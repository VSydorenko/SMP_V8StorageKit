# Track

Статус живе лише в GitHub. Документи (спеки, плани, дорожня карта, BRD) тримають лише зміст. Команда `track` робить GitHub-частину.

## Карта

| Річ | У GitHub | Команда |
|---|---|---|
| Віха дорожньої карти | Milestone | `track milestone "<назва>" [-Due YYYY-MM-DD] [-Description …] [-State open\|closed]` |
| Підпроєкт (одна чи кілька спек) | Issue у віхі | `gh issue create --milestone "<назва>"` |
| Затверджена спека | Issue з міткою `spec`, під-issue підпроєкту | `track spec <spec.md> -Milestone "<назва>" -Parent <#N>` |
| Блок спеки | Під-issue спеки, мітка `block`, «Depends on: #N» | створює `track spec` |
| План блоку | PR з `Refs #<блок>` | — |
| Виконання блоку | PR з `Closes #<блок>` | `pr-gate open` |
| Баг / ідея | Issue з міткою `bug` / `idea` | `gh issue create --label bug` |

## Правила

1. **Питання про статус → `track status`** (`-Milestone "<назва>"` для однієї віхи). Відповідай з його виводу, а не з документів чи пам'яті.
2. **Спеку затверджено → `track spec <спека> -Milestone …`** — після схвалення власника, перед першим планом. Запускай знову щоразу, коли змінилась таблиця блоків; команда ідемпотентна й оновлює лише змінене.
3. **Один блок = один issue = один PR виконання.** Тіло PR виконання має `Closes #<блок>`; PR плану — `Refs #<блок>`, тож блок закривається лише коли його збудовано. `track status` показує PR без `Closes #N`.
4. **Жодного статусу в документах.** Жодних рядків `Status:` з прогресом, чекбоксів, колонок «виконано / у роботі», таблиць статусу в дорожній карті. Дорожня карта посилається на свої віхи.
5. **Статус знайдено в документі** → спершу перенеси в GitHub (створи чи закрий issue, постав віху), потім прибери з документа в тому ж PR. У тілі PR скажи, що куди переїхало.
6. **Спершу `-DryRun`** у репозиторії, який ти ще не вів через `track`; покажи власнику відображення, перш ніж запускати по-справжньому.

## Коди виходу

`0` зроблено · `1` помилка gh або хибна таблиця спеки (повідомлення називає її) · `2` помилка виклику · `3` не перевірено: `gh` відсутній чи не залогінений, немає GitHub-репозиторію (задай `track.repo` у `.agents/kit.profile.json`).
