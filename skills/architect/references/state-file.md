# Файл стану

**Завантаж, коли** береш роль, після кожного злиття чи рішення про розвилку, і першим ділом після стиснення.

Один файл пам'яті сесії архітектора, рядок його індексу позначений «READ FIRST». Лише поточний стан — стискай записи журналу; git тримає історію. Постійні правила власника (моделі, хто пушить, політика злиття) живуть у власних файлах пам'яті з «чому» й «як застосовувати».

```markdown
---
name: architect-state
description: READ FIRST — роль архітектора, сесії, відкриті PR, що чекає на власника
metadata:
  type: project
---

Роль: архітектор <частини> у <репо>. Власник вирішує: продуктове, незворотне,
зовнішні дії. Режим: звичайний | нічний (межі: <…>) | пауза.

## Сесії
| Сесія | Роль | Гілка / робоча копія | Задача | Рішення, передані їй |
| --- | --- | --- | --- | --- |

## Відкриті PR
| PR | Блок | Стан | Наступний крок |

## Чекає на власника
- <питання> — моя рекомендація: <…>

## Прибрати
- <робоча копія / гілка> після <умови>

## Далі
1. <наступна дія>
```

Файл сесій для `session-board -Sessions` (JSON, поруч із брифами):
`{ "<сесія>": { "branch": "<гілка>", "role": "<роль>" } }`.
