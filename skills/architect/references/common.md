# Файл правил серії (`<серія>-common.md`)

**Завантаж, коли** починаєш серію паралельних сесій на одному напрямі.

Один файл у теці брифів; кожен бриф серії посилається на нього. Тримай коротким — його читає кожна сесія.

```markdown
# <серія>: спільні правила

Architect: сесія `<ім'я>`. Рішення власника досі: <ADR-N, …>.

## Vocabulary
Глосарій: <шлях>. Терміни серії: <термін — значення>.

## Project rules that bite
Правила з кореневих файлів проєкту, які сесії порушують найчастіше: режим
workspace.mode і хто тримає базу агента, хто зливає, файли, які править лише власник.
Цитуй; посилайся на кореневий файл.

## Sessions
Файл сесій для `session-board`: <шлях>. Сусідні сесії та їхні гілки перелічені
там; бриф називає сусіда за ім'ям сесії.

## Limits
- Файли, які ніхто в серії не правит без архітектора: <перелік>.
- Один рядок таблиці блоків/інтерфейсів спеки — одна гілка за раз.
- Спільна база агента (режим `shared`): одна сесія, що збирає чи тестує, за раз на воркспейс.

## Tools
Рецензія `review-pack`, журнал `sdd`, PR `pr-gate open` (лише за рядком `Push:`), читання спеки
`doc <спека> §N`, пошук коду — Уніка. Явний `model` у кожному виклику Agent.

## Decisions taken during the series
| Date | Decision | Touches |
| --- | --- | --- |
| <дата> | <один рядок; ADR-N, якщо вагоме> | <сесії / блоки> |
```
