# Формат звіту

**Завантаж, коли** пишеш бриф (скопіюй блок нижче в нього) або отримуєш звіт, що йому не відповідає.

Копіюй у кожен бриф без змін:

```
## Report to the architect
Типи повідомлень — більше нічого в повідомлення не йде:
1. Готово — одне повідомлення, один рядок:
   готово: <PR #N | гілка>, HEAD <sha7>, tests <ok | red: перелік | n/a>, N розвилок, M відхилень
   Деталі (що зроблено, як перевірено з реальним виводом, кожна розвилка й відхилення)
   ідуть у тіло PR; без PR — у <briefs>/<сесія>-report.md, і рядок називає цей шлях
   замість PR.
2. Розвилка, якої бриф не покриває — одне коротке повідомлення: питання, 2–3
   варіанти, твоя рекомендація. Продовжуй незалежні частини.
3. Заблоковано (дозвіл, бракує залежності) — один рядок:
   заблоковано: <що>, потрібно: <що від кого>
Жодних повідомлень про хід роботи, переказів задачі, дампів виводу.
```

Приклади:

```
готово: PR #22, HEAD 7d67179, tests ok, 1 розвилок, 5 відхилень
готово: гілка spike-cache, HEAD 3fa91c2, tests red: db (2 failed), 0 розвилок, 1 відхилень — .agents/briefs/spike-cache-report.md
заблоковано: git push заборонено дозволами, потрібно: дозвіл власника на push гілки issue-40
```



Звіт, що порушує формат: відповідай одним рядком — «звіт у фіксованому форматі, деталі в
тілі PR» — і не читай довгу версію першою.
