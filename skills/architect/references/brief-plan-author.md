# Бриф: автор плану

**Завантаж, коли** блок іде в план (після чекліста з handoff.md).

```markdown
# <сесія>: автор плану <блок> (<проєкт>)

Architect: сесія `<ім'я>`. Series rules: <шлях>-common.md.

## Read
- Скіл `v8storagekit:plan` (форма, розмір і аудит плану).
- Спека: `doc <спека> §3` (рядок блоку), §4 (інтерфейси), §5.<k>.
  ADR: <ADR-N, …>. Глосарій: <шлях>.
- Відомі дельти коду зі зведення: <перелік з file:symbol>.

## Do
- План лише для <блок>. «Готово, коли» плану покриває: <«готово, коли» блоку>.
- Зарезервуй зараз (щоб пізніший механізм додавався без злому): <пункти або «немає»>.
- Незлита робота, від якої залежить план: <X — познач якорі «після X»>.
- Перш ніж почати: звір якорі плану з кодом (`doc anchors <файл>`; код — Уніка:
  `unica.search`, `unica.resolve`); дельти → задача 0 (правка спеки разом із планом).
- Аудит за ризиком за скілом `v8storagekit:plan`; Codex (`codex-companion`) — лише за його тригером і якщо є на машині.

## Subagent models
Аудитори й розвідка: sonnet; лінза безпеки: opus. Явний `model` у кожному виклику Agent.
Аудитори нічого не збирають і в базі агента нічого не запускають.

## Git
Гілка `<гілка>` від origin/<база> (або від <гілки плану A>, якщо залежить від
незлитого плану). Коміт на крок; без rebase/amend/force-push.
PR — лише за рядком брифу; зливати не можна.

<встав блок із report-format.md>
```
