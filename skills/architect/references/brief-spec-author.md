# Бриф: автор спеки

**Завантаж, коли** сесія пише чи правками змінює спеку для архітектора.

```markdown
# <сесія>: автор спеки <напрям> (<проєкт>)

Architect: сесія `<ім'я>`. Series rules: <шлях>-common.md.

## Read
- Скіл `v8storagekit:spec` (три документи, дві таблиці, аудит).
- Уже ухвалені рішення: <ADR-N / відповіді власника з датами>.
- Звіти досліджень: <шляхи>. Ділянки коду: <шляхи, лише читання>.

## Do
- Спека для <обсяг>. Очікувані блоки (можна ділити далі): <B1…>.
- Питання власнику, що лишаються відкритими: <перелік> — тримай їх у §7 із
  рекомендацією; не вирішуй їх.
- Аудит: три лінзи `v8storagekit:auditor`, доки 0 блокерів і 0 security major.

## Subagent models
auditor (спека): sonnet для integrity і truth, opus для security — причина в скілі `v8storagekit:spec`, крок 4; розвідка: sonnet. Явний `model` у кожному виклику Agent.

## Git
Гілка `<гілка>`; коміт на крок, виправлення аудиту окремим комітом; жодних комітів коду.
- Push: <«PR зі спекою після аудиту» | «не пушити»>. PR — лише за цим рядком, через `pr-gate open`; зливати не можна.

<встав блок із report-format.md>
```
