# Бриф: виконавець

**Завантаж, коли** сесія починає виконувати прийнятий план.

```markdown
# <сесія>: виконавець <блок> (<проєкт>)

Architect: сесія `<ім'я>` — розвилки, питання й звіт ідуть туди.
Series rules: <шлях>-common.md (читай першим).

## Read
- Кореневі правила: CLAUDE.md.
- План: <шлях> (прийнятий <дата>). Спека: `doc <спека> §<N>` — рядок блоку
  §3, інтерфейси §4, деталі §5.<k>. ADR: <ADR-N, …>.
- Лише читання: <гілки/робочі копії інших сесій, якщо треба>.

## Do
- Рівно задачі плану; готово, коли = «готово, коли» плану.
- Поза межами: <сусідні блоки й файли, яких не чіпати>.
- Інтерфейси, які споживаєш (не змінюй; зміна — розвилка до мене):
  <ім'я — блок-власник>.
- Залежності від незлитої роботи: <X — що робити, доки не злито>.
- Push: <коли — напр. «після задачі 1, далі після кожної» | «після задач 1, 4, 7» | «лише в кінці блоку, після злиття <блоку Y>» | «не пушити»>.
  Без рядка `Push:` не пушиш і PR не відкриваєш. `pr-gate open` — лише за цим рядком.
- Перевірки: <форма — одним рядком; тести — мінімум, лише на логіку й механізми, які справді треба перевіряти>.
- У репозиторії 1С бриф не дозволяє читати код 1С grep-ом замість Уніки (`git grep` — лише коли Уніка відповіла помилкою чи `uninitialized`, з причиною у звіті).
- Режим робочої копії: <shared | worktree> (`workspace.mode`). Для `shared`: базу агента збираєш і тестуєш лише ти; інші сесії й субагенти-рецензенти її не чіпають.

## Subagent models
| Роль | Модель |
| --- | --- |
| реалізація задачі | sonnet |
| рецензія задачі проти плану | sonnet |
| розвідка, механічні правки документів | sonnet |
| рецензія з лінзою безпеки, вагомі розвилки | opus |
Передавай `model` явно в кожному виклику Agent.

## Tools
- Пакет рецензії: `review-pack`. Журнал: `sdd`.
- PR: за рядком `Push:`; не зливай.

## Git
Режим `worktree`: `pr-gate start <issue> [<slug>]` у головному checkout (створює `<main>/.worktrees/<issue>-<slug>`). Режим `shared`: працюєш у спільному дереві.
Коміт на логічний крок: `git add <перелік>` + `git commit --only -F <файл> -- <ті самі шляхи>`; без rebase, amend, force-push; без stash, reset, `checkout --`, restore, clean.
Push заблоковано дозволами → звітуй «заблоковано», не обходь.

<встав блок із report-format.md>
```
