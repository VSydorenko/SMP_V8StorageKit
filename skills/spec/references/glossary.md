# Глосарій

**Завантаж, коли** додаєш чи змінюєш термін.

Один файл на проєкт (`docs.glossary`, типово `docs/GLOSSARY.md`). Спеки, плани, імена в коді й повідомлення власнику вживають слово з глосарію.

```markdown
# Глосарій

## <Галузь>

**<Термін>** — <що це Є, одне–два речення. Без деталей реалізації.>
*Уникати:* <інші слова, якими це називають>
*Див.:* <спека §N або ADR-N, необов'язково>
```

## Правила

- Один термін — одне значення. Друге значення — другий термін зі своїм словом.
- Термін додають, коли він уперше з'явився в обговоренні чи спеці, а не пачкою наприкінці.
- Лише поняття проєкту. Загальні програмістські слова (timeout, retry, cache) лишаються поза глосарієм, поки проєкт не дасть їм особливого значення.
- Термін змінив значення → зміни запис і кожну спеку, що його вживає, в одному коміті; скажи про це власнику одним рядком.
- Групуй терміни за галузями, коли з'являються скупчення; до того плоский перелік — нормально.
