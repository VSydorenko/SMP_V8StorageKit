# Угоди щодо іменування тестових модулів

Ім'я модуля будується за шаблоном: `[Префікс_][ИмяОбъекта][_Суффикс]`

## Префікси (за типом об'єкта, що тестується)

| Тип об'єкта              | Префікс | Приклад                  |
| ------------------------ | ------- | ------------------------ |
| Загальний модуль         | `ОМ_`   | `ОМ_ОбщегоНазначения`    |
| Документ                 | `Док_`  | `Док_ЗаказПокупателя`    |
| Довідник                 | `Спр_`  | `Спр_Номенклатура`       |
| Регістр відомостей       | `РС_`   | `РС_ЦеныНоменклатуры`    |
| Регістр накопичення      | `РН_`   | `РН_ОстаткиНаСкладах`    |
| Регістр бухгалтерії      | `РБ_`   | `РБ_Хозрасчетный`        |
| Регістр розрахунку       | `РР_`   | `РР_Зарплата`            |
| План рахунків            | `ПС_`   | `ПС_Хозрасчетный`        |
| План видів розрахунку    | `ПВР_`  | `ПВР_Зарплатный`         |
| План видів характеристик | `ПВХ_`  | `ПВХ_Субконто`           |
| План обміну              | `ПО_`   | `ПО_РИБ`                 |
| Обробка                  | `Обр_`  | `Обр_ЗакрытиеМесяца`     |
| Звіт                     | `Отч_`  | `Отч_УниверсальныйОтчет` |
| Перелік                  | `Пер_`  | `Пер_СтатусСогласования` |
| Бізнес-процес            | `БП_`   | `БП_Согласование`        |
| Завдання                 | `Зад_`  | `Зад_Задача`             |

## Суфікси (за типом модуля, що тестується)

| Тип модуля            | Суфікс         | Приклад               |
| --------------------- | -------------- | --------------------- |
| Загальний модуль      | <Без суфікса>  | `ОМ_ОбщегоНазначения` |
| Модуль об'єкта        | `_МО`          | `Спр_Номенклатура_МО` |
| Модуль менеджера      | `_ММ`          | `Спр_Номенклатура_ММ` |
| Модуль набору записів | `_НЗ`          | `РБ_Хозрасчетный_НЗ`  |

## Приклади складених імен

- `Док_ЗаказПокупателя_ММ` — менеджер документа «Заказ покупателя»
- `РН_ОстаткиНаСкладах_НЗ` — набір записів регістра накопичення
- `ПВХ_Субконто_ММ` — менеджер плана видів характеристик
