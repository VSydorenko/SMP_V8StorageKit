# Предикати YAxUnit

## Точка входу

```bsl
ЮТест.Предикат()
```

Створює новий предикат із плинним інтерфейсом. Опційно приймає `Структуру` для автоматичного створення предикатів рівності за парами ключ-значення:

```bsl
Условия = Новый Структура("Наименование, Код", НаименованиеОбъекта, КодОбъекта);
Предикат = ЮТест.Предикат(Условия);
```

---

## Вибір властивості

| Метод | Опис |
|-------|------|
| `Реквизит(ИмяРеквизита)` | Вказує властивість для наступних перевірок. Підтримує точкову нотацію: `"ВложенныйОбъект.Число"`, `"Товары.Номенклатура"` |
| `Свойство(ИмяСвойства)` | Аліас для `Реквизит` |

Якщо не вказано `Реквизит`/`Свойство` — умова застосовується до самого об'єкта.

---

## Порівняння

| Метод | Опис |
|-------|------|
| `Равно(Значение)` | Рівність |
| `НеРавно(Значение)` | Нерівність |
| `Больше(Значение)` | Більше |
| `БольшеИлиРавно(Значение)` | Більше або дорівнює |
| `Меньше(Значение)` | Менше |
| `МеньшеИлиРавно(Значение)` | Менше або дорівнює |

---

## Стан

| Метод | Опис |
|-------|------|
| `Заполнено()` | Заповнено (не порожньо) |
| `Пусто()` | Порожньо/не заповнено |

---

## Тип

| Метод | Опис |
|-------|------|
| `ИмеетТип(ИмяТипа)` | Має вказаний тип |
| `ИмеетТипОтличныйОт(ИмяТипа)` | Тип відрізняється від вказаного |

---

## Довжина/розмір

| Метод | Опис |
|-------|------|
| `ИмеетДлину(Значение)` | Довжина/розмір дорівнює значенню |
| `ИмеетДлинуОтличнуюОт(Значение)` | Довжина/розмір не дорівнює значенню |

---

## Наявність властивості

| Метод | Опис |
|-------|------|
| `ИмеетСвойство(ИмяСвойства)` | Містить вкладену властивість |
| `НеИмеетСвойства(ИмяСвойства)` | Не містить вкладеної властивості |

---

## Входження

| Метод | Опис |
|-------|------|
| `Содержит(Значение)` | Містить значення |
| `НеСодержит(Значение)` | Не містить значення |
| `СодержитСтрокуПоШаблону(Шаблон)` | Рядок відповідає регулярному виразу |
| `НеСодержитСтрокуПоШаблону(Шаблон)` | Рядок не відповідає регулярному виразу |
| `ВСписке(СписокЗначений)` | Значення входить до вказаного списку |

---

## Діапазон

| Метод | Опис |
|-------|------|
| `Между(Начало, Окончание)` / `МеждуВключаяГраницы(Начало, Окончание)` | [Начало, Окончание] |
| `МеждуИсключаяГраницы(Начало, Окончание)` | (Начало, Окончание) |
| `МеждуВключаяНачалоГраницы(Начало, Окончание)` | [Начало, Окончание) |
| `МеждуВключаяОкончаниеГраницы(Начало, Окончание)` | (Начало, Окончание] |

## Получить() — фіналізація предиката

```bsl
.Получить()
```

Повертає копію накопичених умов предиката у вигляді масиву. **Критично** під час збереження предиката в змінну або передавання кількох предикатів — без `.Получить()` предикати ділять один глобальний контекст.

### Неправильно (обидва предикати вказують на один контекст):

```bsl
УсловиеСтрока = ЮТест.Предикат().ИмеетТип("Строка");
УсловиеЧисло = ЮТест.Предикат().ИмеетТип("Число");
// Оба будут "Число"!
```

### Правильно (незалежні копії):

```bsl
УсловиеСтрока = ЮТест.Предикат().ИмеетТип("Строка").Получить();
УсловиеЧисло = ЮТест.Предикат().ИмеетТип("Число").Получить();
```

**Виняток:** `.Получить()` не потрібен, коли предикат передається безпосередньо в метод твердження або Мокито й більше ніде не використовується.

---

## Контексти використання

1. **Твердження колекцій** — `.Содержит(Предикат)`, `.ЛюбойЭлементСоответствуетПредикату(Предикат)`, `.КаждыйЭлементСоответствуетПредикату(Предикат)`
2. **Твердження БД** — `ОжидаетЧтоТаблицаБазы(...).СодержитЗаписи(Предикат)`
3. **Запити даних** — `ЮТЗапросы.Запись(ИмяТаблицы, Предикат)`
4. **Навчання Мокито** — `Мокито.Параметр(Предикат)`

## Реальні приклади з проєкту

### Пошук елемента у Відповідності за ключем і значенням

```bsl
ЮТест.ОжидаетЧто(Результат.Товары[Товар.Код])
    .Свойство("Отрезки")
        .ИмеетТип("Соответствие")
        .ИмеетДлину(2)
        .Содержит(
            ЮТест.Предикат()
                .Реквизит("Ключ").Равно(Отрезок1.Длина)
                .Реквизит("Значение").Равно(Новый Структура("Количество, Длина", Отрезок1.Количество, Отрезок1.Длина)))
        .Содержит(
            ЮТест.Предикат()
                .Реквизит("Ключ").Равно(Отрезок2.Длина)
                .Реквизит("Значение").Равно(Новый Структура("Количество, Длина", Отрезок2.Количество, Отрезок2.Длина)));
```

### Перевірка масиву структур за кількома властивостями

```bsl
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("ФиксированныйМассив")
    .ИмеетДлину(2)
    .Содержит(
        ЮТест.Предикат()
            .Реквизит("Код").Равно(Товары[0].sku)
            .Реквизит("ДлиныОтрезков").Заполнено())
    .Содержит(
        ЮТест.Предикат()
            .Реквизит("Код").Равно(Товары[1].sku)
            .Реквизит("ДлиныОтрезков").Заполнено());
```

### Предикат із кількома умовами на одному реквізиті

```bsl
ЮТест.Предикат()
    .Реквизит("Число")
        .ИмеетТип("Число")
        .Больше(0)
        .Меньше(2)
        .Равно(1)
    .Получить();
```

### Предикат зі структури (скорочений запис)

```bsl
Отбор = ЮТест.Предикат()
    .Реквизит("Источник").Равно(Объект)
    .Реквизит("ТипОповещения").Равно(Справочники.ТипыОповещенийПользователя.Уведомление)
    .Получить();

ЮТест.ОжидаетЧтоТаблицаБазы(ИмяРегистра).НеСодержитЗаписи(Отбор);
// ... вызов метода ...
ЮТест.ОжидаетЧтоТаблицаБазы(ИмяРегистра).СодержитЗаписи(Отбор);
ДанныеУведомления = ЮТЗапросы.Запись(ИмяРегистра, Отбор);
```
