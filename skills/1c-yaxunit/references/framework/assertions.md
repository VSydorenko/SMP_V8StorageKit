# Твердження YAxUnit

## Точка входу

```bsl
ЮТест.ОжидаетЧто(ПроверяемоеЗначение, "Пояснение к ошибке")
```

Повертає модуль `ЮТУтверждения` із плинним (fluent) інтерфейсом. Другий аргумент необов'язковий.

---

## Навігація по об'єкту

| Метод | Опис |
|-------|------|
| `Свойство(ИмяСвойства)` | Перейти до властивості. Підтримує вкладені шляхи |
| `Элемент(Индекс)` | Аліас для `Свойство` — навігація до елемента колекції |
| `Объект()` | Скинути позицію на кореневий об'єкт |
| `НетСвойства(ИмяСвойства)` | Ствердити відсутність властивості й повернутися до кореня |

**Важливо:** `Свойство` завжди розв'язується від кореневого об'єкта, переданого в `ОжидаетЧто`, а НЕ від поточної позиції.

### Підтримувані вирази шляхів

```bsl
.Свойство("Реквизит")                    // прямое свойство
.Свойство("Реквизит.ВложенныйРеквизит")  // вложенное свойство
.Свойство("[0].Товар")                    // элемент коллекции
.Свойство("Товары[0].Товар")              // свойство элемента коллекции
.Свойство("Товары[-1].Сумма")             // последний элемент (отрицательный индекс)
```

## Рівність і порівняння

```bsl
.Равно(Значение)
.НеРавно(Значение)
.Больше(Значение)
.БольшеИлиРавно(Значение)
.Меньше(Значение)
.МеньшеИлиРавно(Значение)
.ВСписке(Коллекция)
```

**Особливості порівняння:**
- Типи порівнюються строго: `1` НЕ дорівнює `Истина` (на відміну від поведінки платформи)
- Глибоке порівняння «за значенням» для Структур, Відповідностей, Масивів, ТаблицьЗначень
- `ХранилищеЗначения` розпаковується перед порівнянням

## Діапазони

```bsl
.МеждуВключаяГраницы(Мин, Макс)          // [Мин, Макс]
.МеждуИсключаяГраницы(Мин, Макс)         // (Мин, Макс)
.МеждуВключаяНачалоГраницы(Мин, Макс)    // [Мин, Макс)
.МеждуВключаяОкончаниеГраницы(Мин, Макс) // (Мин, Макс]
```

## Перевірка винятків

Налаштування ланцюжка: `ЮТест.ОжидаетЧто(Объект).Метод("ИмяМетода").Параметр(Знач1).Параметр(Знач2)`

```bsl
.Метод(ИмяМетода, Параметры)                 // задать имя метода; Параметры — массив (опционально)
.Параметр(Значение)                           // добавить параметр к вызову
.ВыбрасываетИсключение(ОжидаемыйТекст)       // метод должен выбросить исключение, текст которого СОДЕРЖИТ подстроку
.НеВыбрасываетИсключение()                    // метод не должен выбрасывать исключение
```

`Объект` — спільний модуль, менеджер (`РегистрыСведений.X`, `Документы.X`), об'єкт або екземпляр; тип об'єкта на роботу механізму не впливає.

**`.ВыбрасываетИсключение(ОжидаемыйТекст)` — аргумент обов'язковий** (у параметра немає значення за замовчуванням):
- виклик без аргументу падає з `Недостаточно фактических параметров`, а помилка в трейсі прив'язана до рядка `ЮТест.ОжидаетЧто(...)` — виглядає як проблема тестованого методу, але насправді бракує аргументу самому `ВыбрасываетИсключение`;
- збіг **підрядковий** (`СтрНайти(ТекстИсключения, ОжидаемыйТекст) > 0`), не точний і не за префіксом — передавай стійкий фрагмент реального тексту в `НСтр`, а не все формулювання;
- порожній рядок `""` передати не можна — `СтрНайти(..., "")` = 0, перевірка завжди провалиться.

У `.НеВыбрасываетИсключение()` аргумент необов'язковий (є значення за замовчуванням) — викликається без параметрів.

**Важливо:** Ніколи не викликай метод напряму — `Метод(Документ.Записать(...))` — це помилка. Рушій тестування сам викликає метод.

## ОжидаетЧтоТаблицаБазы — перевірка даних у БД

```bsl
ЮТест.ОжидаетЧтоТаблицаБазы(ИмяТаблицы, ОписаниеПроверки)
```

Формат імені таблиці: `"Справочник.Товары"`, `"РегистрСведений.КурсыВалют"`, `"Документ.ЗаказПокупателя"`.

| Метод | Опис |
|-------|------|
| `СодержитЗаписи(Предикат)` | Таблиця містить записи за умовою |
| `НеСодержитЗаписи(Предикат)` | Таблиця не містить записів за умовою |
| `СодержитЗаписиСНаименованием(Наименование)` | Є записи з іменем |
| `СодержитЗаписиСКодом(Код)` | Є записи з кодом |
| `СодержитЗаписиСНомером(Номер)` | Є записи з номером |
| `НеСодержитЗаписиСНаименованием(Наименование)` | Немає записів з іменем |
| `НеСодержитЗаписиСКодом(Код)` | Немає записів з кодом |
| `НеСодержитЗаписиСНомером(Номер)` | Немає записів з номером |

**Рекомендація:** НЕ використовувати `ОжидаетЧтоТаблицаБазы` для перевірки значень полів. Натомість:
1. `ОжидаетЧтоТаблицаБазы` — підтвердити, що запис існує
2. `ЮТЗапросы.Запись(ИмяТаблицы, Условие)` — отримати запис
3. `ЮТест.ОжидаетЧто(Запись)` — перевірити окремі поля

## Віддавай перевагу методам твердження, а не обчисленням у BSL

Якщо в плинного інтерфейсу є метод-перевірка для потрібної характеристики — використовуй його, а не обчислюй цю характеристику в BSL заради перевірки примітива. Такий метод читається як один ланцюжок і точніше виражає намір:

```bsl
// ❌ Хуже — вычисление + примитив, три отдельных ОжидаетЧто
ЮТест.ОжидаетЧто(ТипЗнч(Результат)).Равно(Тип("Структура"));
ЮТест.ОжидаетЧто(Результат.Количество()).Равно(3);
ЮТест.ОжидаетЧто(Результат.Свойство("Штрихкод")).ЭтоИстина();

// ✅ Лучше — одна цепочка утверждений
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("Структура")
    .ИмеетДлину(3)
    .ИмеетСвойство("Штрихкод");
```

Часті відповідності: `ТипЗнч()` + `Равно` → `ИмеетТип`; `.Количество()` + `Равно` → `ИмеетДлину`; `.Свойство()` + `ЭтоИстина` → `ИмеетСвойство` / `НеИмеетСвойства`.

**Це перевага, а не заборона.** Готового методу-перевірки на потрібну характеристику може не бути — тоді обчислення в BSL з перевіркою примітива доречне й нормальне (наприклад, значення треба спершу отримати своїм методом, або характеристика, для якої готової перевірки немає). Правило спрацьовує лише тоді, коли такий метод існує й покриває перевірку; не вигадуй обхідних шляхів, щоб уникнути обчислення там, де без нього не обійтися.

## Реальні приклади з проєкту

### Перевірка типу й значення

```bsl
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("Число")
    .Равно(83.33);
```

### Перевірка структури з вкладеними властивостями

```bsl
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("Структура")
    .Свойство("ДатаДокумента")
        .ИмеетТип("Дата")
        .НеЗаполнено()
    .Свойство("ИнформационнаяБаза")
        .Равно(ИмяИнформационнойБазы)
    .Свойство("Товары")
        .ИмеетТип("Соответствие")
        .НеЗаполнено();
```

### Перевірка масиву з предикатами

```bsl
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("ФиксированныйМассив")
    .ИмеетДлину(2)
    .Содержит(
        ЮТест.Предикат()
            .Реквизит("Код").Равно(Товары[0].sku)
            .Реквизит("ДлиныОтрезков").Заполнено())
    .Содержит(
        ЮТест.Предикат()
            .Реквизит("Код").Равно(Товары[1].sku)
            .Реквизит("ДлиныОтрезков").Заполнено());
```

### Перевірка таблиці значень з індексами рядків

```bsl
ЮТест.ОжидаетЧто(Результат)
    .ИмеетТип("ТаблицаЗначений")
    .Свойство("[0].Краска").Равно(Краска1.Ссылка)
    .Свойство("[0].ВидКолеровки").Равно(Перечисления.ВидыКолеровкиНоменклатуры.КолеровкаВозможна)
    .Свойство("[0].Объем").Равно(5)
    .Свойство("[0].КолеровкаПоУмолчанию").ЭтоЛожь()
    .Свойство("[1].Краска").Равно(Краска2.Ссылка);
```

### Перевірка винятків

```bsl
ЮТест.ОжидаетЧто(ЦелевыеТоварныеЗапасы)
    .Метод("Сформировать", ЮТКоллекции.ЗначениеВМассиве(ОписаниеНастройки))
    .ВыбрасываетИсключение(НСтр("ru = 'Не найдены параметры'"));
```

### Перевірка властивостей структури одним викликом

```bsl
ЮТест.ОжидаетЧто(Результат).ИмеетСвойстваРавные(Ожидание);
```

### Перевірка таблиці бази

```bsl
ЮТест.ОжидаетЧтоТаблицаБазы("РегистрСведений.ЦелевыеОстаткиПодразделений")
    .НеСодержитЗаписи();
```
