# Контексти виконання та директиви компіляції

Застосовується лише до тестових модулів, доступних у клієнті керованого застосунку, — тих, що компілюються і на клієнті, і на сервері.

**Прапорець «Клієнт (звичайний застосунок)».** Він додає модулю контекст `КлиентОбычноеПриложение`. YAxUnit виконує тест лише в контекстах, спільних для модуля й запущеного застосунку. Під час запуску керованого застосунку тести такого модуля йдуть на сервері (і в клієнті керованого застосунку, якщо модуль там доступний), контекст звичайного застосунку не використовується. Він з'являється, лише якщо тести запускають у товстому клієнті звичайного застосунку. Окремих `#Если` для нього не пиши, поки проєкт так тести не запускає.

Головна вимога: **модуль має компілюватися в кожному зі своїх контекстів**. Директиви компіляції ставляться всередині тіла процедур — не навколо самих оголошень процедур.

Усередині клієнт-серверного модуля можуть бути тести трьох видів:

- `ДобавитьТест` — YAxUnit виконує тест в усіх контекстах модуля. Код процедури компілюється і на клієнті, і на сервері; серверно-залежні блоки обгортаються в `#Если Сервер Тогда ... #Иначе ... #КонецЕсли` з клієнтською альтернативою.
- `ДобавитьСерверныйТест` — YAxUnit виконує тест лише на сервері. Процедуру не обгортають цілком — лише конкретні серверно-залежні рядки всередині тіла беруться в `#Если Сервер Тогда ... #КонецЕсли` (без `#Иначе`), бо модуль, як і раніше, компілюється на клієнті.
- `ДобавитьКлиентскийТест` — YAxUnit виконує тест лише на клієнті. Прямий доступ до об'єктів метаданих як до значень (`Справочники.*`, `РегистрыСведений.*`) недоступний — для посилань використовуй `ПредопределенноеЗначение()`, для серверних операцій — `ТестовыеДанныеВызовСервера`.

> **Примітка про Мокито.** Модуль `Мокито` скомпільований для обох контекстів: `Мокито.Обучение()`, `Мокито.Проверить()` і допоміжні функції доступні і на сервері, і на клієнті. Обмеження — в **аргументах**: об'єкти `Справочники.*`, `РегистрыСведений.*` та інші менеджери метаданих існують лише на сервері й не можуть бути передані в Мокито на клієнті напряму. На клієнті замість цього використовуй `ТестовыеДанныеВызовСервера.МокитоОбучениеВернуть()`, який приймає ім'я об'єкта рядком і викликає Мокито на сервері.

## `ДобавитьТест` — обидві гілки через `#Если ... #Иначе`

```bsl
Процедура МетодРаботаетВОбоихКонтекстах() Экспорт
    // given
#Если Сервер Тогда
    Товар = Справочники.Номенклатура.Доставка;
    Мокито.Обучение(РегистрыСведений.ЗначенияСвойствОбъектов)
        .Когда("НайтиОбъектыПоСвойствуИЗначению")
            .Вернуть(ЮТКоллекции.ЗначениеВМассиве(Товар))
        .Прогон();
#Иначе
    Товар = ПредопределенноеЗначение("Справочник.Номенклатура.Доставка");
    ТестовыеДанныеВызовСервера.МокитоОбучениеВернуть(
        "РегистрыСведений.ЗначенияСвойствОбъектов",
        "НайтиОбъектыПоСвойствуИЗначению",
        ЮТКоллекции.ЗначениеВМассиве(Товар));
#КонецЕсли

    // when
    Результат = МойМодуль.МойМетод(Товар);

    // then
    ЮТест.ОжидаетЧто(Результат).ЭтоИстина();
КонецПроцедуры
```

## `ДобавитьСерверныйТест` — серверні рядки без `#Иначе`, решта коду спільна

```bsl
Процедура МетодТребуетСервернуюПроверку() Экспорт
    // given
    Товар = Неопределено;
#Если Сервер Тогда
    Товар = Справочники.Номенклатура.Доставка;
    Мокито.Обучение(Справочники.ПравилаПодбораБарабанов)
        .Когда("ПолучитьДиапазоны")
            .Вернуть(Новый ФиксированныйМассив(Новый Массив()))
        .Прогон();
#КонецЕсли

    // when
    Результат = МойМодуль.МойМетод(Товар);

    // then
    ЮТест.ОжидаетЧто(Результат).ИмеетТип("ФиксированныйМассив");
#Если Сервер Тогда
    Мокито.Проверить(Справочники.ПравилаПодбораБарабанов)
        .КоличествоВызовов("ПолучитьДиапазоны")
        .Равно(1);
#КонецЕсли
КонецПроцедуры
```

## Ключові відмінності між контекстами

- **Сервер**: прямий доступ до об'єктів метаданих (`Справочники.*`, `РегистрыСведений.*`) як до значень — для передавання в методи і в `Мокито.Обучение()`
- **Клієнт**: посилання на предопределені значення через `ПредопределенноеЗначение("Справочник.Номенклатура.ПустаяСсылка")`, мокування через `ТестовыеДанныеВызовСервера.МокитоОбучениеВернуть()` (приймає ім'я об'єкта рядком)
