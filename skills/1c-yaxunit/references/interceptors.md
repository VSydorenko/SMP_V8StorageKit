# Створення мок-перехоплювачів

Мокито працює через механізм розширень 1С (`&Вместо`). Щоб замокувати метод, у тестовому розширенні має існувати файл-перехоплювач із відповідною функцією `&Вместо`.

## Крок 1 — перевір, чи вже існує перехоплювач

Спочатку перевір, чи є в тестовому розширенні потрібний об'єкт і файл перехоплювача для потрібного модуля. Де лежать метадані об'єкта й файл модуля — розділ «Розкладка файлів» у `references/project-format.md`. Об'єкти основної конфігурації й інших розширень шукай через Уніку (`unica.search`, `unica.view`), а не grep по XML.

- **Файл модуля існує** → просто додай нову функцію `&Вместо` у кінець файлу (якщо код файлу обгорнуто в інструкцію препроцесора — всередину обгортки, див. правила кроку 2). Метадані й реєстрацію не чіпай.
- **Об'єкт запозичений, файлу потрібного модуля немає** (наприклад, перехоплено модуль об'єкта, а потрібен модуль менеджера) → створи BSL-файл (крок 2) і виконай дії для цього стану з `references/project-format.md` (крок 3).
- **Об'єкт не запозичений** → створи перехоплювач: BSL-файл (крок 2), запозичення об'єкта й реєстрація (крок 3).

## Крок 2 — BSL-файл перехоплювача

**Шаблон для функції:**

```bsl
&Вместо("ИмяМетода")
Функция Мок_ИмяМетода(Парам1, Парам2) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Парам1, Парам2);

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(ОбъектМодуля, "ИмяМетода", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(Парам1, Парам2);
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции
```

**Шаблон для процедури:**

```bsl
&Вместо("ИмяПроцедуры")
Процедура Мок_ИмяПроцедуры(Парам1) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Парам1);

	ПрерватьВыполнение = Ложь;
	МокитоПерехват.АнализВызова(ОбъектМодуля, "ИмяПроцедуры", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		ПродолжитьВызов(Парам1);
	КонецЕсли;

КонецПроцедуры
```

**Правила:**
- `&Вместо("ИмяМетода")` — ім'я методу в оригінальному модулі, рядок
- Ім'я функції: `Мок_[ИмяМетода]`
- Параметри — точно як в оригіналі (включно з `Знач` і значеннями за замовчуванням)
- `Экспорт` — лише якщо оригінальний метод експортний; обробники подій об'єкта (`ПередЗаписью`, `ПриЗаписи` тощо) не експортні — `Экспорт` не потрібен
- `ОбъектМодуля` в `АнализВызова` — змінна-посилання на об'єкт, не рядок:
  - Загальний модуль: `ИмяМодуля`
  - Менеджер документа: `Документы.ИмяДок`
  - Менеджер довідника: `Справочники.ИмяСпр`
  - Менеджер регістра: `РегистрыСведений.ИмяРС`
  - Модуль об'єкта документа чи довідника: `ЭтотОбъект` (екземпляр, не менеджер)
  - Набір записів регістра відомостей: `ЭтотОбъект` (екземпляр набору записів)
- Для **модуля об'єкта** мок у тесті налаштовується на конкретний екземпляр, а не на менеджер:

  ```bsl
  // Менеджер:
  Мокито.Обучение(Документы.ЗаказПокупателя).Когда("МойМетод").Вернуть(42).Прогон();
  // Объект:
  Объект = Документы.ЗаказПокупателя.СоздатьДокумент();
  Мокито.Обучение(Объект).Когда("МойМетод").Вернуть(42).Прогон();
  ```

- `ПродолжитьВызов(...)` — передає ті самі параметри, що отримали, зайвих не додавай
- **Інструкція препроцесора.** Перехоплювачу потрібна лише одна інструкція — та, якою модуль об'єкта, менеджера чи набору записів виключає клієнтський контекст (#std680): `#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда ... #КонецЕсли`. Порядок слів в умові може відрізнятися, важливий склад: `Сервер`, `ТолстыйКлиентОбычноеПриложение`, `ВнешнееСоединение`.
  - Метод в оригінальному модулі знаходиться всередині такої інструкції (на будь-якому рівні вкладеності) — обгорни перехоплювач у неї. Кілька перехоплювачів одного файлу — всередині однієї спільної обгортки.
  - Такої інструкції навколо методу немає — обгортка не потрібна.
  - Решту інструкцій оригіналу не повторюй, навіть якщо метод знаходиться всередині них (наприклад, `#Если НЕ МобильныйАвтономныйСервер Тогда`). Гілку `#Иначе ВызватьИсключение ...` з модуля об'єкта теж не переноси — вона вже є в оригіналі.

  ```bsl
  #Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

  &Вместо("ИмяМетода")
  Функция Мок_ИмяМетода(Парам1) Экспорт
  	// ... тело по шаблону выше
  КонецФункции

  #КонецЕсли
  ```

  Чому: обгортка задає лише контекст компіляції перехоплювача — він має компілюватися там само, де перехоплюваний метод. Структуру коду оригіналу відтворювати не потрібно.

**Приклад із кількома методами в одному файлі:**

```bsl
&Вместо("ЭтоКолеровка")
Функция Мок_ЭтоКолеровка(Знач Услуга) Экспорт

	ПараметрыМетода = Мокито.МассивПараметров(Услуга);

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(КолеровкаПовтИсп, "ЭтоКолеровка", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(Услуга);
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции

&Вместо("ПолучитьУслугиКолеровки")
Функция Мок_ПолучитьУслугиКолеровки() Экспорт

	ПараметрыМетода = Мокито.МассивПараметров();

	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(КолеровкаПовтИсп, "ПолучитьУслугиКолеровки", ПараметрыМетода, ПрерватьВыполнение);

	Если НЕ ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов();
	Иначе
		Возврат Результат;
	КонецЕсли;

КонецФункции
```

## Крок 3 — метадані й реєстрація (лише під час створення нового файлу модуля)

Перехоплювач — це **adopted**-розширення наявного об'єкта основної конфігурації. Об'єкт запозичує Уніка (`unica.apply`, скіли `unica:cfe-borrow`, `unica:cfe-patch-method`); як запозичити об'єкт для перехоплювача чи доповнити вже запозичений і як зареєструвати його в розширенні — розділи «Запозичення об'єкта для перехоплювача» і «Реєстрація» в `references/project-format.md`, довідка для звірки результату.
