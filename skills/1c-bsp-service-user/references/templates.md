# Шаблони коду: службовий користувач і бібліотека БСП

Перевірено на 8.3.27.1644, БСП 3.1.7. Префікс `Мой` заміни своїм. Ідентифікатори — російською.

## 1. Перехоплення реєстрації бібліотеки

Запозичений `ОбщийМодуль.ПодсистемыКонфигурацииПереопределяемый`, модуль у розширенні:

```bsl
&После("ПриДобавленииПодсистем")
Процедура Мой_ПриДобавленииПодсистем(МодулиПодсистем)
	
	МодулиПодсистем.Добавить("Мой_Обновление");
	
КонецПроцедуры
```

## 3. Налаштування користувача (модуль `Мой_Настройка`, сервер)

```bsl
// Фіксований GUID елемента довідника: обробник знаходить «свого» користувача між оновленнями.
Функция ИдСлужебногоПользователя()
	Возврат "0108066b-0000-4000-8000-000000000000"; // згенеруй свій один раз
КонецФункции

Функция ИмяСлужебногоПользователя() Экспорт
	Возврат "Мой_Service";
КонецФункции

Процедура НастроитьСлужебногоПользователя() Экспорт
	
	Если НЕ ПравоДоступа("Администрирование", Метаданные) Тогда
		ВызватьИсключение НСтр("ru = 'Недостаточно прав для настройки служебного пользователя.'");
	КонецЕсли;
	
	Ссылка = Справочники.Пользователи.ПолучитьСсылку(Новый УникальныйИдентификатор(ИдСлужебногоПользователя()));
	Объект = Ссылка.ПолучитьОбъект();
	НужнаЗапись = Ложь;
	
	Если Объект = Неопределено Тогда
		Объект = Справочники.Пользователи.СоздатьЭлемент();
		Объект.УстановитьСсылкуНового(Ссылка);
		Объект.Наименование = НСтр("ru = 'Служебный пользователь интеграции'");
		НужнаЗапись = Истина;
	КонецЕсли;
	Если НЕ Объект.Служебный Тогда
		Объект.Служебный = Истина;
		НужнаЗапись = Истина;
	КонецЕсли;
	
	ПользовательИБ = Неопределено;
	Если ЗначениеЗаполнено(Объект.ИдентификаторПользователяИБ) Тогда
		ПользовательИБ = ПользователиИнформационнойБазы.НайтиПоУникальномуИдентификатору(
			Объект.ИдентификаторПользователяИБ);
	КонецЕсли;
	Если ПользовательИБ = Неопределено Тогда
		ПользовательИБ = ПользователиИнформационнойБазы.НайтиПоИмени(ИмяСлужебногоПользователя());
	КонецЕсли;
	
	Описание = Пользователи.НовоеОписаниеПользователяИБ();
	Описание.Вставить("Действие", "Записать");
	Описание.Имя = ИмяСлужебногоПользователя();
	Описание.ПолноеИмя = Объект.Наименование;
	Описание.АутентификацияСтандартная = Истина; // без неї сеанс від імені користувача не стартує
	Описание.ПоказыватьВСпискеВыбора = Ложь;
	Описание.ЗапрещеноИзменятьПароль = Истина;
	Описание.Роли = Новый Массив;
	Описание.Роли.Добавить(Метаданные.Роли.БазовыеПраваБСП.Имя);
	Описание.Роли.Добавить(Метаданные.Роли.Мой_Служебный.Имя);
	
	Если ПользовательИБ = Неопределено Тогда
		// Пароль випадковий і ніде не зберігається: увійти інтерактивно не можна, а сеансу,
		// який запускає платформа від імені користувача (WebSocket), пароль не потрібен.
		Описание.Пароль = НовыйСлучайныйПароль();
		НужнаЗапись = Истина;
	Иначе
		Описание.УникальныйИдентификатор = ПользовательИБ.УникальныйИдентификатор;
		Если НЕ ПользовательИБ.АутентификацияСтандартная Тогда
			Описание.Пароль = НовыйСлучайныйПароль();
		КонецЕсли;
		Если ПользовательИБНужноПравить(ПользовательИБ) Тогда
			НужнаЗапись = Истина;
		КонецЕсли;
	КонецЕсли;
	
	Если НужнаЗапись Тогда
		Объект.ДополнительныеСвойства.Вставить("ОписаниеПользователяИБ", Описание);
		Объект.Записать(); // БСП створить або оновить користувача ІБ за описом
	КонецЕсли;
	
КонецПроцедуры

Функция ПользовательИБНужноПравить(ПользовательИБ)
	
	Если НЕ ПользовательИБ.Роли.Содержит(Метаданные.Роли.БазовыеПраваБСП)
		Или НЕ ПользовательИБ.Роли.Содержит(Метаданные.Роли.Мой_Служебный) Тогда
		Возврат Истина;
	КонецЕсли;
	Возврат НЕ ПользовательИБ.АутентификацияСтандартная
		Или ПользовательИБ.ПоказыватьВСпискеВыбора
		Или НЕ ПользовательИБ.ЗапрещеноИзменятьПароль
		Или ПользовательИБ.АутентификацияОС
		Или ПользовательИБ.АутентификацияOpenID;
	
КонецФункции

Функция НовыйСлучайныйПароль()
	// Два GUID v4. Якщо в проєкті є криптографічно стійкий генератор байтів — краще він.
	Возврат СтрЗаменить(Строка(Новый УникальныйИдентификатор) + Строка(Новый УникальныйИдентификатор), "-", "");
КонецФункции

// Для індикатора у формі: чи відпрацювало оновлення. Звичайний користувач список користувачів ІБ не бачить.
Функция СлужебныйПользовательСоздан() Экспорт
	УстановитьПривилегированныйРежим(Истина);
	Создан = ПользователиИнформационнойБазы.НайтиПоИмени(ИмяСлужебногоПользователя()) <> Неопределено;
	УстановитьПривилегированныйРежим(Ложь);
	Возврат Создан;
КонецФункции
```

Модуль з `УстановитьПривилегированныйРежим` має бути один і без коду, куди доходять зовнішні запити.

## 4. Форма: попередження, поки користувача немає

Надпис `ПредупреждениеНастройки` у метаданих форми **видимий**, тож розробник бачить його в конфігураторі. Фон —
`style:ToolTipBackColor`.

```bsl
&НаСервере
Процедура ПоказатьПредупреждениеНастройки()
	Создан = Мой_Настройка.СлужебныйПользовательСоздан();
	Элементы.ПредупреждениеНастройки.Видимость = НЕ Создан;
	Элементы.ГруппаОсновная.Доступность = Создан;   // без службового користувача форма недоступна
КонецПроцедуры
```

Текст: «Не настроено: нет служебного пользователя. Администратору нужно один раз запустить базу с ключом запуска
/C ЗапуститьОбновлениеИнформационнойБазы».

## 5. Тест «щойно встановлене» (поза звичайним прогоном)

```bsl
ПользовательИБ = ПользователиИнформационнойБазы.НайтиПоИмени(Мой_Настройка.ИмяСлужебногоПользователя());
Если ПользовательИБ <> Неопределено Тогда
	ПользовательИБ.Удалить();
КонецЕсли;
Объект = Справочники.Пользователи.ПолучитьСсылку(Новый УникальныйИдентификатор(<GUID>)).ПолучитьОбъект();
Если Объект <> Неопределено Тогда
	Объект.ОбменДанными.Загрузка = Истина; // обробники БСП пропускаються: користувача ІБ уже видалено
	Объект.Удалить();
КонецЕсли;
```

Далі людина двічі запускає базу з `/C ЗапуститьОбновлениеИнформационнойБазы`. Після першого запуску користувач є.
Після другого UUID користувача ІБ той самий, а події `_$User$_.New` у ЖР немає.
