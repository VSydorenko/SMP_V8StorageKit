# Шаблони коду: WebSocket-з'єднання в розширенні

Префікс `Мой` заміни своїм. Ідентифікатори — російською. Назва події журналу — основною мовою конфігурації, `НСтр` з
кодом основної мови й усіма мовами конфігурації (#std498 п. 2.1; скіл `v8storagekit:1c-localization`). Розділи 4–6 перевірено на 8.3.27.1644 у продукті.
Розділи 1–3 — схема постійного каналу за спекою munin-mcp від 02.11.2026: поведінку платформи, на якій вона стоїть,
виміряно (`behavior.md`), а сам код у продукті ще не перевірено.

## 1. Постійний канал: одна функція «привести до норми»

Ідемпотентна; кличуть регламентне завдання раз на 60 с, кнопка «Перепідключити» й обробник оновлення. Нічого не
чекає: те, що потребує часу, завершує наступний виклик.

```bsl
Функция ПривестиКанал() Экспорт
	
	Если НЕ Мой_Настройка.СлужебныйПользовательСоздан() Тогда
		Возврат "НеНастроен";
	КонецЕсли;
	
	Соединение = НайтиСоединение(КлючКанала());
	Состояние = СостояниеСоединения(Соединение); // Неопределено, якщо з'єднання немає чи стан не прочитано
	
	Если Состояние = Неопределено Или Состояние = СостояниеWebSocketСоединения.Закрыто Тогда
		Открыть(); // повторний виклик з ключем живого з'єднання нічого не робить
		Возврат "Открытие";
	КонецЕсли;
	
	Если Состояние <> СостояниеWebSocketСоединения.Открыто Тогда
		Если ДавноПробовалиОткрыть() Тогда // «Открывается»/«Закрывается» довше 60 с
			Закрыть(Соединение);
			Возврат "Переподключение";
		КонецЕсли;
		Возврат "Открывается";
	КонецЕсли;
	
	Если Соединение.URLСервера <> Мой_Настройка.АдресСервера() Или ДавноНетКадровОтСервера() Тогда
		Закрыть(Соединение); // ключ звільниться за ≤3 с — відкриє наступний виклик
		Возврат "Переподключение";
	КонецЕсли;
	
	// Мертве «Открыто» видно лише на вихідному кадрі: відправка падає, з'єднання закривається.
	Если НЕ ОтправитьКаналу(Соединение, Новый Структура("type", "keepalive")) Тогда
		Возврат "Переподключение";
	КонецЕсли;
	
	Возврат "Работает";
	
КонецФункции

Функция КлючКанала()
	Возврат "мой.канал"; // фіксований: платформа не дасть відкрити другий
КонецФункции

Функция НайтиСоединение(Ключ)
	Попытка
		Для Каждого Одно Из WebSocketКлиентСоединения.ПолучитьСоединения() Цикл
			Если Одно.Ключ = Ключ Тогда
				Возврат Одно;
			КонецЕсли;
		КонецЦикла;
	Исключение
	КонецПопытки;
	Возврат Неопределено;
КонецФункции

Процедура Открыть()
	
	Обработчики = Новый ОбработчикиWebSocketКлиентСоединения;
	Обработчики.Модуль = "Мой_КаналОбработчики"; // загальний серверний модуль, обробники — експортні (розділ 3)
	Обработчики.ОбработчикОткрытияСоединения = "ПриОткрытииСоединения";
	Обработчики.ОбработчикПолученияСообщения = "ПриПолученииСообщения";
	Обработчики.ОбработчикОшибки = "ПриОшибке";
	Обработчики.ОбработчикЗакрытияСоединения = "ПриЗакрытииСоединения";
	
	ЗаписатьПопыткуОткрытия(); // час спроби — для «Открывается довше 60 с»
	Попытка
		WebSocketКлиентСоединения.ОткрытьСоединение(КлючКанала(), Мой_Настройка.АдресСервера(), Обработчики,
			Новый ПараметрыWebSocketКлиентСоединения, Мой_Настройка.ИмяСлужебногоПользователя());
	Исключение
		ЗаписьЖурналаРегистрации(НСтр("ru = 'Мой.КаналНеОткрыт'", ОбщегоНазначения.КодОсновногоЯзыка()),
			УровеньЖурналаРегистрации.Предупреждение);
	КонецПопытки;
	
КонецПроцедуры
```

У регістр стану пиши лише за зміни (результат, час спроби), подію ЖР — лише на дію. Інакше щохвилинний запуск
дає тисячі рядків на добу.

## 2. Регламентне завдання

Предвизначене, період 60 с, метод — `Мой_ПроверкаКанала.Выполнить` → `ПривестиКанал()`. Воно ж — вимикач каналу:
`Использование = Ложь` + `Закрыть()` з'єднання, а `ПривестиКанал()` на вимкненому завданні нічого не відкриває.
Якщо канал має працювати на копії бази (сказати серверу «я копія»), не реєструй завдання в БСП як таке, що працює із
зовнішніми ресурсами: БСП вимкне його на копії.

## 3. Обробники в загальному модулі `Мой_КаналОбработчики`: лише делегування в `Попытка`

```bsl
// Обробник ніколи не завершується винятком: виняток губить кадр і стан рукостискання.

Процедура ПриОткрытииСоединения(Соединение) Экспорт
	Попытка
		Мой_Канал.ПриОткрытии(Соединение);
	Исключение
		Мой_Канал.ОбработатьОшибкуОбработчика("ПриОткрытии", Соединение);
	КонецПопытки;
КонецПроцедуры

Процедура ПриПолученииСообщения(Соединение, Сообщение) Экспорт
	Попытка
		Мой_Канал.ПриСообщении(Соединение, Сообщение);
	Исключение
		Мой_Канал.ОбработатьОшибкуОбработчика("ПриСообщении", Соединение);
	КонецПопытки;
КонецПроцедуры

Процедура ПриОшибке(Соединение, КодОшибки, Описание) Экспорт
	Попытка
		Мой_Канал.ПриОшибке(КодОшибки); // опис не пишемо: може містити адресу
	Исключение
		Мой_Канал.ОбработатьОшибкуОбработчика("ПриОшибке", Неопределено);
	КонецПопытки;
КонецПроцедуры

Процедура ПриЗакрытииСоединения(Соединение, КодЗакрытия) Экспорт
	Попытка
		Мой_Канал.ПриЗакрытии(Соединение); // КодЗакрытия завжди 1005 — не аналізувати
	Исключение
		Мой_Канал.ОбработатьОшибкуОбработчика("ПриЗакрытии", Неопределено);
	КонецПопытки;
КонецПроцедуры
```

На початку `Мой_Канал.ПриОткрытии` перевір, що `ИмяПользователя()` — службовий користувач, а
`Соединение.URLСервера` — налаштована адреса. Інакше закрий без жодного кадру.

## 4. Обробка помилки обробника (`Мой_Канал`)

```bsl
// Викликається з розділу Исключение обробника: ИнформацияОбОшибке() — про його виняток.
Процедура ОбработатьОшибкуОбработчика(ИмяОбработчика, Соединение) Экспорт
	
	Место = "?";
	Попытка
		Информация = ИнформацияОбОшибке();
		Места = Новый Массив;
		Пока Информация <> Неопределено Цикл
			Места.Добавить(Информация.ИмяМодуля + ":" + Формат(Информация.НомерСтроки, "ЧН=0; ЧГ=0"));
			Информация = Информация.Причина;
		КонецЦикла;
		Место = СтрСоединить(Места, " <- ");
	Исключение
		Место = "?";
	КонецПопытки;
	
	Попытка
		// Лише місце, без опису: опис може містити дані кадру чи адресу.
		ЗаписьЖурналаРегистрации(НСтр("ru = 'Мой.ОшибкаОбработчика'", ОбщегоНазначения.КодОсновногоЯзыка()),
			УровеньЖурналаРегистрации.Ошибка, , ,
			"Обработчик: " + ИмяОбработчика + " | место: " + Место);
	Исключение
	КонецПопытки;
	
	Если Соединение <> Неопределено Тогда
		Попытка
			Соединение.Закрыть();
		Исключение
		КонецПопытки;
	КонецЕсли;
	
КонецПроцедуры
```

## 5. Безпечна відправка

```bsl
Процедура Отправить(Соединение, Текст, ПервыйКадр = Ложь) Экспорт
	
	Попытка
		Состояние = Соединение.ПолучитьСостояние();
	Исключение
		Возврат; // стан не прочитано — вважати не відкритим
	КонецПопытки;
	
	// «Открывается» — кадр пішов би в наступний сокет. Перший кадр рукостискання — лише не в «Закрыто».
	Если ПервыйКадр Тогда
		МожноОтправить = Состояние <> СостояниеWebSocketСоединения.Закрыто;
	Иначе
		МожноОтправить = Состояние = СостояниеWebSocketСоединения.Открыто;
	КонецЕсли;
	Если НЕ МожноОтправить Тогда
		Возврат;
	КонецЕсли;
	
	Попытка
		Соединение.ОтправитьСообщение(Текст);
	Исключение
		ЗаписьЖурналаРегистрации(НСтр("ru = 'Мой.КадрНеОтправлен'", ОбщегоНазначения.КодОсновногоЯзыка()),
			УровеньЖурналаРегистрации.Предупреждение);
		Попытка
			Соединение.Закрыть();
		Исключение
		КонецПопытки;
	КонецПопытки;
	
КонецПроцедуры
```

Протокол із сервером: після рукостискання кожен кадр несе ідентифікатор фізичного з'єднання `conn`, виданий
сервером на цей сокет. Стан лежить у регістрі за (ключ з'єднання, conn); кадр із чужим conn відкидається мовчки.

## 6. Динамічне з'єднання від імені користувача

Ім'я — лише з власного реєстру, рядок якого користувач створив у своєму сеансі (власник — UUID користувача ІБ з
сеансу). Сервер передає тільки ідентифікатор реєстрації.

```bsl
Функция ОткрытьКаналПользователя(ИдРегистрации, URL) Экспорт
	
	Регистрация = Мой_Регистрации.НайтиПоИдентификатору(ИдРегистрации);
	Если Регистрация = Неопределено Или НЕ Регистрация.Активна
		Или ПустаяСтрока(Регистрация.ИмяПользователяИБ) Тогда
		Возврат Ложь; // без імені — ніколи: сеанс отримав би повні права
	КонецЕсли;
	
	Обработчики = Новый ОбработчикиWebSocketКлиентСоединения;
	Обработчики.Модуль = "Мой_КаналПользователя"; // загальний модуль, обробники — експортні
	Обработчики.ОбработчикОткрытияСоединения = "ПриОткрытииСоединения";
	Обработчики.ОбработчикПолученияСообщения = "ПриПолученииСообщения";
	Обработчики.ОбработчикОшибки = "ПриОшибке";
	Обработчики.ОбработчикЗакрытияСоединения = "ПриЗакрытииСоединения";
	
	Параметры = Новый ПараметрыWebSocketКлиентСоединения;
	Параметры.ДополнительныеПараметры = Новый Структура("ИдРегистрации", ИдРегистрации);
	
	// Ключ глобальний: унікальний на кожне відкриття.
	Ключ = "мой.пользователь." + ИдРегистрации + "." + НРег(Строка(Новый УникальныйИдентификатор));
	Попытка
		WebSocketКлиентСоединения.ОткрытьСоединение(Ключ, URL, Обработчики, Параметры,
			Регистрация.ИмяПользователяИБ);
	Исключение
		ЗаписьЖурналаРегистрации(НСтр("ru = 'Мой.КаналНеОткрыт'", ОбщегоНазначения.КодОсновногоЯзыка()),
			УровеньЖурналаРегистрации.Предупреждение);
		Возврат Ложь;
	КонецПопытки;
	Возврат Истина; // робочим вважати лише після першої відповіді обробника
	
КонецФункции
```

Перевірка власника в `Мой_КаналПользователя` — перед першим кадром і перед кожною дією:

```bsl
Функция ЭтоВладелец(ИдРегистрации)
	Регистрация = Мой_Регистрации.НайтиПоИдентификатору(ИдРегистрации); // під RLS «лише свої рядки»
	Возврат Регистрация <> Неопределено И Регистрация.Активна
		И Регистрация.ИдентификаторПользователяИБ
			= ПользователиИнформационнойБазы.ТекущийПользователь().УникальныйИдентификатор
		И РольДоступна("Мой_ПравоРаботы");
КонецФункции
```

Сеанс без імені має нульовий UUID, тож власником не буде. Реєстрацію з такого сеансу заборони окремо: в ньому
`РольДоступна()` повертає Истина. Заблокованого користувача перевіряй так; якщо прочитати не вдалося — вважай
заблокованим:

```bsl
Функция ПользовательЗаблокирован(ИдПользователяИБ)
	Попытка
		Если ПараметрыСеанса.ТекущийПользователь.Недействителен Тогда
			Возврат Истина;
		КонецЕсли;
		Возврат НЕ Пользователи.ВходВПрограммуРазрешен(ИдПользователяИБ); // привілейований режим БСП вмикає сама
	Исключение
		Возврат Истина;
	КонецПопытки;
КонецФункции
```
