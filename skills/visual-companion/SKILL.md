# Visual companion

Локальна вкладка браузера, що показує HTML-екрани, які пише агент, і записує кліки власника. Прості структури лишаються діаграмою mermaid у тексті.

## Запропонувати

Коли вперше постає візуальне питання, запропонуй companion окремим повідомленням, одним рядком, без іншого тексту:

> «Це простіше показати. Відкрити вкладку браузера з макетами?»

Якщо власник відмовився — лишайся в тексті й не пропонуй вдруге, доки сам не попросить. Рішення — на кожне питання, не на всю сесію: вимоги, обсяг і компроміси лишаються в тексті, навіть коли власник погодився на браузер.

## Старт

Лише після згоди власника:

```powershell
pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/skills/visual-companion/scripts/start-server.ps1" -ProjectDir "<корінь git>" -Open
```

Скрипт друкує один рядок JSON з `url`, `screen_dir`, `state_dir` — збережи їх. Власнику давай **повний** `url`, разом із `?key=…`: сервер відхиляє запити без ключа. Файли сесії лежать у `<проєкт>/.agents/out/companion/` (тека не комітиться). Сервер працює на Node, тож `node` має бути в PATH.

## Кожен екран

Перед першим екраном прочитай `references/guide.md`: цикл роботи, формат HTML-фрагмента, CSS-класи, файл подій.

## Стоп

Коли обговоренню браузер більше не потрібен:

```powershell
pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/skills/visual-companion/scripts/stop-server.ps1" "<тека сесії — батьківська для screen_dir>"
```

Скрипт друкує `{"status": "stopped"}`. Сервер також зупиняється сам після 4 годин простою.
