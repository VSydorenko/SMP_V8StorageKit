# Протокол верифікатора

**Завантажуй**, коли верифікуєш знахідку рев'ю — свою чи чужу.

Завдання — «**спростуй це**», а не «перевір це». **Типово — спростовано**: ні доказів у той, ні в інший бік → `REFUTED (unproven)`. Хибна знахідка коштує дорожче за пропущену дрібницю: галасливий звіт перестають читати.

## Порядок — від найдешевшого

1. **Чи існує місце** і чи виглядає як описано? Ні → `REFUTED`. Код знаходь через Уніку (`unica_view`, `unica_search`, `unica_resolve`), потім `git grep`; Уніки немає — `git grep`/Grep.
2. **Чи воно в межах diff?** Існувало раніше → `REFUTED (pre-existing)`.
3. **Чи є вище охорона** — перевірка, тип, виклик, що перевіряє першим, — через яку сценарій недосяжний?
4. **Чи можливі такий вхід чи стан** за типами, метаданими, гарантіями виклику?
5. **Чи канон проєкту приписує саме це** (правила проєкту, спека)? Чи знахідка судить прототип за цільовим правилом, або навпаки?
6. **Чи відтворюється?** Прогін чи мутація важать більше за міркування. Режим `worktree`: мутуй лише в одноразовій копії: `t=$(pr-gate scratch add <head>)` друкує унікальний шлях відокремленого worktree; потім прибери `pr-gate scratch rm "$t"`. Якщо `scratch add` не вдався — зупини мутацію й скажи про це, спільне робоче дерево ніколи не запасний варіант. Режим `shared` (1С): мутації й прогону в базі агента немає — база спільна; напиши в `WHY`, що відтворення прогоном чи мутацією не було («Не перевірено»).

## Вердикт

```
VERDICT: CONFIRMED | REFUTED | PARTIAL
CONFIDENCE: NN
WHY: 1–3 речення — що перевірено й що побачено
EVIDENCE: file:line + фрагмент, вхід або вивід прогону
RESTATEMENT: (лише PARTIAL) точне істинне твердження
```

`PARTIAL` — справжнє, але не так чи не там, як описано. Оціни впевненість за шкалою формату звіту (посилання зі `SKILL.md`).

## Правила

- Одна знахідка на верифікатора. Інших дефектів не шукай.
- Читай код, а не міркування рецензента.
- Базу агента не збирай, не запускай у ній нічого, мутуючих інструментів Уніки (`unica_apply`, `unica_run`) не клич.
- Два верифікатори на blocker; вони не бачать вердиктів один одного.
