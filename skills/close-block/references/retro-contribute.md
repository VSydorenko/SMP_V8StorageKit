# Внести патерн kit

**Завантаж, коли** власник обрав пункт kit із ретро.

Плагін процесу — `v8storagekit`: репозиторій `VSydorenko/SMP_V8StorageKit`. Внесок несе докази з реальної сесії; загальні поради не приймаються.

## Дві копії процесу

Процес існує ще й в agent-kit (ADR-0001, «Consequences»): урок одного оточення в інше сам не потрапляє. Якщо знахідка загальна для обох оточень (не залежить від 1С, бази агента чи сховища), запропонуй власнику ще й перенос в `VSydorenko/agent-kit` — окремим issue з тим самим доказом; сам його не створюй без вибору власника.

## Маршрут

| Що | Маршрут |
|---|---|
| Новий скрипт, скіл, агент, правило чи зміна процесу | Issue з міткою `pattern` |
| Мале виправлення наявного скрипта чи скіла (баг, хибний прапорець, пропущений випадок), до ~50 змінених рядків | Pull request |

Власник уже схвалив назву й підсумок у питанні ретро.

## Issue

`gh issue create -R VSydorenko/SMP_V8StorageKit --label pattern --title "<коротке твердження>" --body-file <файл>`. Розділи тіла:

1. **Проблема** — що агенти роблять зараз і що це коштує (ходи, токени, поправки власника).
2. **Докази** — проєкт, дата, числа; цитуй щонайбільше кілька рядків. Жодних секретів, даних клієнтів чи приватних імен, бо репозиторій спільний.
3. **Пропозиція** — скрипт, правило скіла чи хук; його інтерфейс у кількох рядках.
4. **Де вписується** — яку наявну частину плагіна змінює, якщо є.

## Pull request

1. Репозиторій плагіна — його власний checkout; роби в гілці чи worktree за правилами цього репозиторію (`pr-gate start <N>`, коли є issue; без issue відкрий його першим). Сторожа git немає, але заборони ті самі: жодних stash/reset/`checkout --`/restore/clean у спільному дереві.
2. Змінюй лише своє. Скіли адресуй з префіксом `v8storagekit:`; правила щодо шляхів у `SKILL.md` і бамп версії в `.claude-plugin/plugin.json` — як у `CLAUDE.md` репозиторію плагіна.
3. Перевір зачеплені тести плагіна цільовим прогоном (`tools/tests/Run-Tests.ps1 -ExcludeTag Integration -Only <файли>`).
4. Закоміть свої шляхи, потім `pr-gate open -Title … -BodyFile <файл>` із доказами. Це єдиний push; ніколи в одному виклику Bash із `git push` чи `gh pr merge`, бо класифікатор відхиляє весь виклик.
5. Зливає архітектор після перевірки.

Конвенції плагіна — `CLAUDE.md` його репозиторію.
