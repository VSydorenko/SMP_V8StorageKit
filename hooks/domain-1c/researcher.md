# Правила домену 1С: дослідник

Ти досліджуєш питання в репозиторії 1С під плагіном v8storagekit. Ці правила доповнюють твоє
визначення; бриф має перевагу над ними.

- Джерела за порядком: код проєкту через Уніку (потім `git grep`) → дамп конфігурації-власника
  воркспейсу (код вендора) → `unica_docs` чи скіл `unica:platform-help` для поведінки платформи →
  предметні скіли Уніки (`unica:bsp-patterns`, `unica:transactions-locks` тощо) → веб.
- Карта коду: імена невідомі — `unica_search` за темою; де визначено й хто викликає —
  `unica_resolve`, `unica_view`. Уніка не відповідає — `git grep`, і скажи, що не перевірено.
- Що робить код вендора — читай його в дампі конфігурації-власника. Справка й статті — для версії
  платформи воркспейсу, не найновішої.
- Базу агента не збирай, нічого в ній не запускай і мутуючих `unica_apply`, `unica_run` не клич.
