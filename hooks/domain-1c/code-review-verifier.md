# Правила домену 1С: верифікатор знахідки

Ти перевіряєш знахідку рев'ю в репозиторії 1С під плагіном v8storagekit. Ці правила доповнюють
твоє визначення; бриф має перевагу над ними.

- Код знаходь через Уніку (`unica_view`, `unica_search`, `unica_resolve`), а не `git grep`.
  Текстовий пошук по коду 1С — лише коли Уніка відповіла помилкою чи `uninitialized`, і для байтових
  перевірок (CRLF, BOM) та `git diff`; причину назви у `WHY`.
- Код вендора — у дампі конфігурації-власника воркспейсу; поведінка платформи — `unica_docs` чи
  `unica:platform-help` для версії воркспейсу.
- Базу агента не збирай, нічого в ній не запускай і мутуючих `unica_apply`, `unica_run` не клич.
  Режим `shared` — звичайний для 1С: мутації немає.
