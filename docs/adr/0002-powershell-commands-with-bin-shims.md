# ADR-0002: Скрипти процесу — команди kit на PowerShell з короткими обгортками в `bin/`

Status: accepted 2026-11-19; замінено частково 2026-11-21 — окремий вхід `tools/kit-process.ps1` змінено єдиним входом `kit.exe` (ADR-0014); решта рішення діє
Decided by: architect
Source: agent-kit 0.9.1 (оригінал, `.agents/private/agent-kit` у ворктрі блоку); окремої спеки немає — рішення власника 2026-11-19

## Context

Скрипти agent-kit — Node без залежностей; v8storagekit — PowerShell 7 з Pester і одним
диспетчером `tools/kit.ps1`. Агенти мають кликати скрипти коротко й однаково з обох
інструментів: Bash (Git Bash) і PowerShell.

Вимір 2026-11-19 (Claude Code 2.1.328, `claude -p --plugin-dir`): тека `bin/` плагіна є в
`PATH` обох інструментів. У Bash виконується файл без розширення (shebang), у PowerShell —
`<ім'я>.ps1`, коли поруч лежать `.ps1` і `.cmd`.

## Decision

Логіку пишемо командами kit на PowerShell (`tools/commands/<команда>.psm1`, модулі
`tools/lib/`). Для кожної команди процесу плагін постачає дві обгортки в `bin/`: `<команда>`
(bash, з бітом виконання) і `<команда>.ps1`; обидві кличуть `pwsh -NoProfile -File
tools/kit-process.ps1 <команда> <аргументи>`. Агент кличе `sdd dispatch 3 -Model sonnet` з
будь-якого інструмента.

Вхід команд процесу — окремий `tools/kit-process.ps1` **без param-блоку**, а не `tools/kit.ps1`:
параметри `kit.ps1` (`-RepoRoot`, `-Source`, …) і загальні параметри PowerShell перехоплюють
токени команд процесу ще на прив'язці (`sdd fix 3 -Source controller`; `review-pack -Out` —
неоднозначний префікс `-OutVariable`/`-OutBuffer`), а `--` у `pwsh -File` для скрипта з
`[CmdletBinding()]` дає помилку прив'язки (вимір 2026-11-19). Корінь репозиторію —
поточна тека.

## Why

- Одна мова, один набір тестів (Pester, підпроцес справжнього `kit.ps1` на синтетичному
  репозиторії), один стиль параметрів.
- Node-код agent-kit має POSIX-припущення (групи процесів, `/proc`, `/` у шляхах), тож
  перенос «як є» однаково вимагав би переписування.

## Rejected

- Node-скрипти agent-kit з виправленнями під Windows — друга мова й другий тестовий стек у
  плагіні.
- Лише повна форма `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" …` — довго, і
  правила дозволів довелося б писати з шляхом конкретної машини.

## Consequences

Старт `pwsh` коштує ~350 мс на виклик (вимір 2026-11-19); для скриптів процесу це прийнятно.
Для хука, що спрацьовує на кожну команду, — ні: див. ADR-0007.
