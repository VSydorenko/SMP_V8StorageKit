# ADR-0007: Сторож git — на Bash і PowerShell; правила спільного дерева — механізм

Status: rejected 2026-11-19 — власник: «не впевнений, що такий сторож тут треба»; git у 1С допоміжний, робочий код і поточну версію тримає сховище 1С. Повернутись, якщо інцидент повториться
Decided by: architect
Source: agent-kit 0.9.1 (оригінал, `.agents/private/agent-kit` у ворктрі блоку); окремої спеки немає — рішення власника 2026-11-19

## Context

Глобальні правила власника забороняють у спільному дереві `git checkout -- <шлях>`,
`git restore`, `git stash`, `git clean`. 2026-09-15 субагент так стер чужу незакомічену
роботу в SMP_SimplyConnect. Правило в тексті такого не зупиняє. Сторож agent-kit
(`hooks/guard-git.mjs`) ловить ці дії лише на брудному дереві, лише в Bash і лише в синтаксисі
POSIX-оболонки. Тут є ще й інструмент PowerShell. Вимір 2026-11-19: хук PreToolUse з
matcher `PowerShell` спрацьовує, команда — в `tool_input.command`.

Старт `pwsh` — ~350 мс, `node` — ~100 мс (вимір 2026-11-19). Хук спрацьовує на кожну команду.

## Decision

1. PreToolUse на `Bash` і `PowerShell`. Команда хука — короткий bash-фільтр: якщо в
   `tool_input.command` немає слів `git`/`gh`, вихід 0 без запуску `pwsh`.
2. Розбір і рішення — PowerShell-модуль сторожа: токенізатор POSIX-оболонки (форма
   agent-kit: `$(…)`, heredoc, `bash -c`, `eval`, аліаси git) і токенізатор PowerShell
   (`&`, `-Command`, `Invoke-Expression`, here-string, `git.exe`, повний шлях).
3. Завжди заборонено: `checkout -- <шлях>` і `checkout -f`, `restore` (крім `--staged`),
   `stash`, `clean -f`, `reset --hard`, `push --force*`, `+ref`, `push --delete`, `gh pr merge`.
4. Лише в режимі `shared`: `git add -A|--all|.` і `commit -a` — відмова з підказкою точкового
   коміту.
5. Коли профіль має секцію `pr`: сирий `git worktree add|remove` → `pr-gate`.
6. Відмова — `permissionDecision: deny` з причиною й правильною командою. Зламаний вхід або
   профіль — пропуск (сторож не ламає сесію).

## Why

- Правило в тексті вже раз не спрацювало; механізм не залежить від того, чи прочитав агент
  CLAUDE.md.
- Фільтр тримає ціну хука на командах без git у межах старту bash.

## Rejected

- Відмова лише на брудному дереві (форма agent-kit) — дерево «чисте» для сесії, яка не бачить
  чужих застейджених змін в іншому воркспейсі; правило власника суворіше.
- Node-сторож — друга мова в плагіні заради ~250 мс, які знімає фільтр.

## Consequences

Власник за потреби виконує заборонену дію сам через `! <команда>`. Обсяг дії — усі проєкти
машини чи лише ті, що мають профіль процесу — вирішує власник (П3).
