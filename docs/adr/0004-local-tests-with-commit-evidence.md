# ADR-0004: Тести 1С — локально через раннер; доказ прогону прив'язаний до коміту

Status: superseded by ADR-0010 (2026-11-21); до того — deferred 2026-11-19
Decided by: architect
Source: agent-kit 0.9.1 (оригінал, `.agents/private/agent-kit` у ворктрі блоку); окремої спеки немає — рішення власника 2026-11-19

## Context

agent-kit тримає правило «локально — лише цільові тести, повні рівні — CI на draft PR», а
злиття — лише після зеленого CI на точному коміті голови PR. Для 1С CI немає: прогін потребує
платформи, ліцензії й бази. Тести YaXUnit запускає раннер Уніки
(`v8-runner test yaxunit module|all --json-message`). Виміряні пастки прогону (ранбук
оточення, `platform-traps.md`):

- модуль може мовчки не підхопитись: зведення `0/0/0/0` виглядає зеленим;
- асинхронний клієнтський тест зелений за будь-якого коду;
- `testScope=all` обривається таймаутом раннера ~5 хв;
- `test` збирає з робочого дерева, а не з коміту: чужі незакомічені правки потрапляють у
  прогін;
- одна база агента на воркспейс: паралельні прогони псують одна одній стан.

## Decision

1. Повні рівні 1С запускаються локально, лише через `run-tests`, послідовно на базі агента.
2. `run-tests` записує **доказ прогону** `.agents/evidence/<sha>/<рівень>.json` лише тоді,
   коли прогін відбувся на чистому дереві source-set-ів рівня і `HEAD` = `<sha>`. Інакше
   результат друкується, але доказом не стає.
3. `total = 0` для названого модуля — «не перевірено» (код 3), не зелений.
4. Гейт злиття — доказ на точному коміті голови PR для рівнів `pr.requiredLevels`. Якщо
   власник дозволить, `pr-gate` публікує доказ статусом коміту в GitHub
   (`v8storagekit/tests:<рівень>`), і решта логіки гейту agent-kit працює без змін.
5. «Тест уміє впасти» доводиться червоним доказом на коміті тесту, зробленому до коміту
   виправлення. Форма agent-kit `--at <rev>` (переписати дерево старим кодом) у спільному
   дереві заборонена: вона перезаписує файли інших сесій.

## Why

- Доказ на коміті замінює CI-перевірку на точному SHA, яку agent-kit вважає єдиним доказом.
- Покомітний протокол «спершу червоний тест» уже прийнятий у SMP_SimplyConnect
  (`docs/agent-sessions-protocol.md` §2) — тут він стає механізмом, а не домовленістю.

## Rejected

- Без гейту злиття — повертає «тести — випадковість».
- Самостійний CI-раннер з 1С на GitHub — ліцензія й база на чужій машині; поза межами.

## Consequences

Повний рівень займає базу агента; архітектор упорядковує прогони сесій, що ділять базу, як
agent-kit упорядковує push блоків на спільному CI.
