# B6. Міграція репозиторіїв 0.6.0 на маніфест — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** команда `kit migrate` і скіл `v8storagekit:migrate`, які переводять репозиторій
конвенції 0.6.0 (`<Продукт>/storage.json`, `v8project.local.yaml` з `devInfobase:`) на маніфест
`v8storagekit.yaml` + накладку, будують дзеркала `storage/*` повторним реплеєм зі сховища,
роблять перше злиття в головну гілку й доводять `verify` до `equal`; прогін — на **тестовому
репозиторії, який надасть користувач** (спека §14), не на живих `SMP_SimplyConnect`/`SMP_BankExchange`.

**Architecture:** детермінована частина (інвентаризація `storage.json` і `v8project.local.yaml`
→ маніфест + накладка, вилучення `storage.json`, звуження `v8project.local.yaml` до бази агента,
рядки `.gitattributes`/`.gitignore` під фактичні шляхи) — команда `migrate` з тестами на
синтетичному репозиторії 0.6.0; решта (перейменування тек під імена розширень, страхувальний
bundle, реплей, злиття, звірка) — скіл, що викликає `sync`/`verify`/`install-hooks`. Історія
старого реплею на головній гілці лишається як архів (§9).

**Tech Stack:** PowerShell 7.5, Pester 5, git 2.53, платформа 1С (Integration — реплей на тестовому репо).

**Spec:** `docs/superpowers/specs/2026-09-03-agent-contour-design.md` — §9 (кроки міграції), §2.2
(ім'я розширення в трьох місцях), §3.4 (перше злиття), §13 (OnlineExchange — окремо), §14 (B6).

## Global Constraints

- **Живі репозиторії `SMP_SimplyConnect`, `SMP_BankExchange` у цьому блоці не чіпати** — лише
  читати як зразок структури. Прогін — на репозиторії `<TEST_REPO>`, шлях якого дає користувач.
- **Страхувальний bundle перед будь-якою зміною** тестового репо: `git bundle create`.
- Сховища — тільки читання; `-Apply` — лише на прохання; `git push` — ні; версію не піднімати.
- Мова — українська; ASCII-якорі; правило `${CLAUDE_PLUGIN_ROOT}`; префікси скілів.
- Локальний маркетплейс уже стоїть (B1 Task 10): скіл `migrate` доступний у сесії тестового репо.
- **Kit не покладається на git-конфіг машини споживача (принцип 7 спеки; знахідка живого прогону B2):**
  `core.quotepath` типово `true`, і git екранує неASCII-шляхи вісімково в лапках у `ls-tree`, `ls-files`,
  `status`, `diff` — на репозиторії 1С це 240+ хибних «файлів поза шляхом». Правило (рев'ю B2):
  `-c core.quotepath=false` — на **кожному** git-виклику, що читає або друкує шляхи, без винятків;
  **`-z` додатково** — там, де викликач ділить вивід на записи **і** запис міг створити не kit (довільний ref,
  довільна робоча копія): `Export-KitTree`, `Get-KitBinaryPaths`, `canon status`. Пояснення: `quotepath`
  керує лише байтами ≥ 0x80, а `"`, `\` і перевід рядка git C-квотує завжди — `-z` прибирає саме це.
  Фікстурам заборонено виставляти `core.quotepath` — це маскувало б дефект (у SMP_BankExchange він був
  замаскований локальним `.git/config`).
- **`Mock -ModuleName` не перетинає межу модуля (знахідка B3):** щойно виклик платформи переїжджає з
  `commands/X.psm1` у `lib/Y.psm1`, моки `-ModuleName X` мовчки перестають перехоплювати — тести лишаються
  зеленими й тихо піднімають справжній `1cv8.exe`. Приймальна ознака тесту без платформи — не час виконання, а
  явне `Should -Invoke … -ModuleName <модуль, де ТЕПЕР живе виклик>`; при кожному перенесенні коду між модулями
  моки переадресовуються.
- **Уроки B1, обов'язкові для виконавця:**
  1. *Приймальна ознака попереджень* — не рахунок рядків `warning:` (недетермінований, змішує навмисне з
     випадковим), а іменна: «жоден `warning:` не називає файлу з цього diff'у».
  2. *Дисципліна коміту в спільній робочій копії* — лише `git add <явний перелік>` +
     `git commit --only -- <ті самі шляхи>`; ніяких `-a`/`-A`; після `git update-index` — комітити негайно.
  3. *Кеш плагіна — знімок, не лінк:* після кожного блоку (і перед живою перевіркою скілів/хука) —
     `claude plugin install v8storagekit@smp-v8storagekit` (або `update`) і **нова сесія**; без цього сесії
     бачать попередню версію робочої копії.

```powershell
#Requires -Version 7
Set-StrictMode -Version Latest

function Read-KitLegacyProduct {
    param([Parameter(Mandatory)][string]$Dir)
    $json = Get-Content -LiteralPath (Join-Path $Dir 'storage.json') -Raw -Encoding UTF8 | ConvertFrom-Json
    $project = Read-V8Project -Path (Join-Path $Dir 'v8project.yaml')
    $extSet  = $project.SourceSets | Where-Object Type -eq 'EXTENSION' | Select-Object -First 1
    $baseSet = $project.SourceSets | Where-Object Type -eq 'CONFIGURATION' | Select-Object -First 1
    $localPath = Join-Path $Dir 'v8project.local.yaml'
    $dev = $null; $localStorage = $null; $agent = $null
    if (Test-Path -LiteralPath $localPath) {
        $local = Read-KitYaml -Path $localPath -AllowEmpty
        if ($local -and $local.Contains('devInfobase') -and $local['devInfobase'] -is [System.Collections.IDictionary]) {
            $dev = [pscustomobject]@{ Connection = [string]$local['devInfobase']['connection']; User = $(if ($local['devInfobase'].Contains('user')) { [string]$local['devInfobase']['user'] } else { '' }) }
        }
        if ($local -and $local.Contains('storagePath')) { $localStorage = [string]$local['storagePath'] }
        if ($local -and $local.Contains('infobase')) { $agent = $local['infobase'] }
    }
    [pscustomobject]@{
        Path = Split-Path -Leaf $Dir; Dir = $Dir
        ExtensionName = [string]$json.extensionName; StoragePath = [string]$json.storagePath; SourcePath = [string]$json.sourcePath
        SourceSetName = $(if ($extSet) { $extSet.Name } else { $null }); ExtPath = $(if ($extSet) { $extSet.Path } else { 'cfe/src' })
        BaseName = $(if ($baseSet) { $baseSet.Name } else { $null }); BasePath = $(if ($baseSet) { $baseSet.Path } else { $null })
        Dev = $dev; LocalStorage = $localStorage; AgentInfobase = $agent; LocalPath = $localPath
        NeedsRename = ((Split-Path -Leaf $Dir) -ne [string]$json.extensionName) -or ($extSet -and $extSet.Name -ne [string]$json.extensionName)
    }
}

function Invoke-KitMigrate {
    <#
    .SYNOPSIS
        Репозиторій 0.6.0 (storage.json, devInfobase:) → v8storagekit.yaml + v8storagekit.local.yaml (спека §9, крок 1).
        Гілок і платформи не торкається; перейменування тек — за скілом migrate (git mv), бо це рішення людини.
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]$Context,
        [string]$Workspace,
        [string]$Source,
        [bool]$Apply,
        [Parameter(Mandatory)][ValidateSet('product', 'client')][string]$Kind,
        [Parameter(Mandatory)][string]$Label
    )
    $root = $Context.RepoRoot
    if (Test-Path -LiteralPath (Join-Path $root 'v8storagekit.yaml')) { throw "У $root вже є v8storagekit.yaml — репозиторій уже мігровано; далі kit check / v8storagekit:onboarding для нових джерел." }

    $products = @(Get-ChildItem -LiteralPath $root -Directory | Where-Object { Test-Path -LiteralPath (Join-Path $_.FullName 'storage.json') } | Sort-Object Name |
        ForEach-Object { Read-KitLegacyProduct -Dir $_.FullName })
    $epfDirs = @(Get-ChildItem -LiteralPath $root -Directory | Where-Object {
        (Test-Path -LiteralPath (Join-Path $_.FullName 'v8project.yaml')) -and -not (Test-Path -LiteralPath (Join-Path $_.FullName 'storage.json')) } |
        ForEach-Object { $p = Read-V8Project -Path (Join-Path $_.FullName 'v8project.yaml'); if ($p.SourceSets | Where-Object Type -eq 'EXTERNAL_DATA_PROCESSORS') { [pscustomobject]@{ Path = $_.Name; Project = $p } } })
    if ($products.Count -eq 0) { throw "У $root немає тек зі storage.json — мігрувати нічого. Новий репозиторій підключає v8storagekit:onboarding." }

    # --- маніфест ---
    $m = [System.Collections.Generic.List[string]]::new()
    $m.Add('version: 1'); $m.Add("${Kind}: $Label"); $m.Add('workspaces:')
    $overlayIb = [ordered]@{}; $overlayStorages = [ordered]@{}
    $attrLines = [System.Collections.Generic.List[string]]::new(); $ignoreLines = [System.Collections.Generic.List[string]]::new()
    foreach ($p in $products) {
        $devKey = "dev$($p.Path)"
        $m.Add("  - path: $($p.Path)"); $m.Add('    sources:')
        if ($p.BaseName) {
            $m.Add("      $($p.BaseName): { truth: vendor, dump: { from: $devKey } }")
            $ignoreLines.Add("$($p.Path)/$($p.BasePath)/**")
            $attrLines.Add("$($p.Path)/$($p.BasePath)/** -text")
        }
        $key = if ($p.SourceSetName) { $p.SourceSetName } else { $p.ExtensionName }
        $m.Add("      ${key}:"); $m.Add('        truth: storage'); $m.Add("        storage: { path: '$($p.StoragePath)' }")
        $attrLines.Add("$($p.Path)/$($p.ExtPath)/** -text")
        if ($p.Dev) { $overlayIb[$devKey] = $p.Dev }
        if ($p.LocalStorage) { $overlayStorages[$key] = $p.LocalStorage }
    }
    foreach ($e in $epfDirs) {
        $m.Add("  - path: $($e.Path)"); $m.Add('    sources:')
        foreach ($s in ($e.Project.SourceSets | Where-Object Type -eq 'EXTERNAL_DATA_PROCESSORS')) {
            $m.Add("      $($s.Name): { truth: git }"); $attrLines.Add("$($e.Path)/$($s.Path)/** -text")
        }
    }
    $o = [System.Collections.Generic.List[string]]::new()
    if ($overlayIb.Count) { $o.Add('infobases:'); foreach ($k in $overlayIb.Keys) { $o.Add("  ${k}:"); $o.Add("    connection: '$($overlayIb[$k].Connection)'"); if ($overlayIb[$k].User) { $o.Add("    user: '$($overlayIb[$k].User)'") } } }
    if ($overlayStorages.Count) { $o.Add('storages:'); foreach ($k in $overlayStorages.Keys) { $o.Add("  ${k}: '$($overlayStorages[$k])'") } }

    Write-Host "Знайдено продуктів: $($products.Count); тек зовнішніх обробок: $($epfDirs.Count)"
    foreach ($p in $products) {
        $flag = if ($p.NeedsRename) { "  ← тека/name ≠ ім'я розширення '$($p.ExtensionName)': перейменувати (git mv) і виправити name: у v8project.yaml — робить скіл" } else { '' }
        Write-Host "  $($p.Path): розширення $($p.ExtensionName), сховище $($p.StoragePath)$flag"
    }
    Write-Host ''; Write-Host '--- v8storagekit.yaml ---'; $m | ForEach-Object { Write-Host $_ }
    Write-Host ''; Write-Host '--- v8storagekit.local.yaml ---'; if ($o.Count) { $o | ForEach-Object { Write-Host $_ } } else { Write-Host '(порожньо)' }
    Write-Host ''; Write-Host '--- .gitattributes (дописати) ---'; $attrLines | ForEach-Object { Write-Host $_ }
    Write-Host '--- .gitignore (дописати) ---'; $ignoreLines | ForEach-Object { Write-Host $_ }

    if (-not $Apply) {
        Write-Host ''; Write-Host 'Це попередній перегляд. Для виконання додайте -Apply.' -ForegroundColor Cyan
        return [pscustomobject]@{ ExitCode = 0; Products = $products }
    }

    Set-Content -LiteralPath (Join-Path $root 'v8storagekit.yaml') -Value ($m -join "`n") -Encoding UTF8
    if ($o.Count) { Set-Content -LiteralPath (Join-Path $root 'v8storagekit.local.yaml') -Value ($o -join "`n") -Encoding UTF8 }
    foreach ($p in $products) {
        git -C $root rm -q --cached -- "$($p.Path)/storage.json" 2>$null | Out-Null
        Remove-Item -LiteralPath (Join-Path $p.Dir 'storage.json') -Force
        if (Test-Path -LiteralPath $p.LocalPath) {
            if ($p.AgentInfobase) {
                $keep = @('infobase:') + @(foreach ($k in $p.AgentInfobase.Keys) { "  ${k}: '$($p.AgentInfobase[$k])'" })
                Set-Content -LiteralPath $p.LocalPath -Value ($keep -join "`n") -Encoding UTF8
            } else { Remove-Item -LiteralPath $p.LocalPath -Force }
        }
    }
    $ga = Join-Path $root '.gitattributes'; $gi = Join-Path $root '.gitignore'
    $gaText = if (Test-Path $ga) { Get-Content $ga -Raw } else { "* text=auto`n" }
    foreach ($l in $attrLines) { if ($gaText -notmatch [regex]::Escape($l)) { $gaText = $gaText.TrimEnd("`r", "`n") + "`n$l`n" } }
    Set-Content -LiteralPath $ga -Value $gaText -Encoding UTF8 -NoNewline
    $giText = if (Test-Path $gi) { Get-Content $gi -Raw } else { '' }
    foreach ($l in @($ignoreLines) + @('v8storagekit.local.yaml')) { if ($giText -notmatch [regex]::Escape($l)) { $giText = $giText.TrimEnd("`r", "`n") + "`n$l`n" } }
    Set-Content -LiteralPath $gi -Value $giText -Encoding UTF8 -NoNewline

    Write-Host ''; Write-Host 'Готово: маніфест і накладка записані, storage.json вилучено, v8project.local.yaml звужено до бази агента.' -ForegroundColor Green
    Write-Host 'Далі: git mv для тек, що не дорівнюють імені розширення; kit install-hooks -Apply; kit check; коміт; kit sync -Apply; kit verify.'
    [pscustomobject]@{ ExitCode = 0; Products = $products }
}
```

````markdown
# migrate — репозиторій 0.6.0 → маніфест і дзеркала (разово)

Після використання на всіх репозиторіях скіл вилучається (спека §6). Живі репозиторії
мігруються лише після прогону на тестовому й зворотного зв'язку (спека §14). Старий gitsync/EDT
репозиторій (`AUTHORS`+`VERSION`+`DT-INF/`) — це не цей скіл: довідка
`${CLAUDE_PLUGIN_ROOT}/docs/migration/legacy-gitsync-repo.md`, рішення окреме.

## 1. Розвідка й страховка (лише читання + bundle)

1. Корінь репо, чиста робоча копія, поточна гілка — головна (`main`/`master`).
2. `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" migrate -RepoRoot . -Kind <product|client> -Label <Назва>` — прев'ю:
   продукти, запропонований маніфест і накладка, рядки політик, і **які теки треба перейменувати**
   (тека або `name:` source-set ≠ ім'я розширення).
3. Страхувальний bundle: `git bundle create ../<репо>-pre-migrate-<дата>.bundle --all` і
   `git bundle verify` його.

## 2. Кроки (спека §9)

1. **Маніфест і накладка:** той самий `migrate … -Apply`. Перевірити накладку: ключі дев-баз
   `dev<Продукт>` — перейменувати на осмислені (`devUNF`, `devBP`) і в маніфесті (`dump.from`), і
   в накладці, якщо людина хоче.
2. **Перейменування** (лише позначені в прев'ю): `git mv <Тека> <ІмʼяРозширення>`; у
   `v8project.yaml` — `name:` EXTENSION = ім'я розширення; у маніфесті — `path:` і ключ джерела.
   Кириличне ім'я — сказати вголос (follow-ups §10).
3. **Хуки:** `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" install-hooks -RepoRoot . -Apply`
   (стейджить `.githooks/*` з режимом 100755 — перевірка `git ls-files -s .githooks/`).
4. **Перевірка:** `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" check -RepoRoot .` — без `[-]`.
5. **Коміт:** `git add -A && git commit -m "migrate: маніфест v8storagekit.yaml замість storage.json; хуки"`.
6. **Дзеркала повторним реплеєм** (не `git filter-repo --path`: він зберіг би SHA, але тягне окрему
   утиліту; реплей — хвилини й тестований шлях): для кожного джерела
   `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" sync -RepoRoot . -Source <ключ> -Apply`
   (для великого сховища — порціями `-MaxVersions`, тоді перше злиття — `-MergeMain` наприкінці).
   Історія старого реплею на головній гілці лишається як архів.
7. **Перше злиття** робить `sync` (`--allow-unrelated-histories`): дерева мають збігатись, diff
   порожній, коміт фіксує спільного предка. **Конфлікт** означає, що дерево 0.6.0 розійшлося з
   платформою (найчастіше — стара політика тексту): `git merge --abort` уже зроблено kit; звірити
   `verify -Ref storage/<ключ>` (канонічність дзеркала) і розв'язувати на боці сховища —
   сховище істина.
8. **Звірка:** `pwsh -NoProfile -File "${CLAUDE_PLUGIN_ROOT}/tools/kit.ps1" verify -RepoRoot .` —
   `equal` для кожного джерела (BankExchange дав нуль змістовних розбіжностей на 516 файлах).
9. Доповідь людині: що перейменовано, скільки версій реплеєно, вердикт `verify`, шлях до bundle.

## 3. Штатні зупинки

`migrate`: «вже є v8storagekit.yaml» — мігровано; «немає тек зі storage.json» — `v8storagekit:onboarding`.
`sync`/`verify`/`check` — зупинки їхніх скілів. Невідомі автори при реплеї — `AUTHORS` (старий файл
уже містить більшість).

## 4. Межі
````
