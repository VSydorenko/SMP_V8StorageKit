# D2. Команда `kit tests` — тестовий контур бази агента — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** kit сам перевіряє, чи база агента готова до `operation=test` з YaXUnit (розширення є, версія не нижча за потрібну, безпечний режим і захист від небезпечних дій зняті). На файловій базі він доставляє відсутнє з `-Apply` ідемпотентно; на серверній — встановлює відсутнє розширення, а решту чесно називає неперевіреною з інструкцією для людини.

**Architecture:** необов'язкове поле `tests:` воркспейсу в маніфесті (`Manifest.psm1`) → новий lib-модуль `TestContour.psm1`. Там чисті функції (розбір виводу `ibcmd`, порівняння версій, пошук пакета, **рішення** «ок / доставити / зупинка») і тонкі обгортки платформи (читання стану, встановлення, зняття прапорців). У `V8.psm1` — запуск `ibcmd` і декодер його змішаного кодування. Команда `tools/commands/tests.psm1` лише складає це докупи: прочитати → вирішити → з `-Apply` виконати → перечитати → вирішити знову. Код виходу визначає останнє рішення. Далі `finish` кличе команду перед `operation=test`, а `onboarding` оголошує тестовий source-set.

**Tech Stack:** PowerShell 7, Pester 5, `powershell-yaml`, платформа 1С 8.3.27.x (`1cv8.exe`, `ibcmd.exe`).

**Spec:** `docs/superpowers/specs/2026-09-23-test-contour-design.md` — §3 (рішення Р1–Р4), §4, §5 (увесь), §6.1, §6.3–§6.5, §10, §11.

## Global Constraints

- Коди виходу `kit tests`: `0` — контур цілий; `3` — є що доставити, і `-Apply` це вміє; `1` — зупинка, потрібна людина (спека §5.2). Після `-Apply` код визначає **повторна перевірка** (§5.2).
- Без `-Apply` команда нічого не змінює; вона лише читає базу платформою (§5.2).
- Р2: на будь-якій базі kit лише **додає**: встановлює відсутнє розширення, знімає прапорці. На серверній базі версію розширення не оновлює.
- Файлова база: стан читає `ibcmd extension info --db-path=… --name=…`; прапорці знімає `ibcmd extension update … --safe-mode=no --unsafe-action-protection=no` (§5.4, вимір 2026-09-23).
- Серверна база: kit бачить лише імена розширень (`DESIGNER /DumpDBCfgList -AllExtensions`). Версію й прапорці він називає неперевіреними — код `1` з інструкцією для Конфігуратора (§5.4).
- Встановлення — **двома** викликами Конфігуратора: `/LoadCfg "<cfe>" -Extension <ім'я>`, потім `/UpdateDBCfg -Extension <ім'я>`. Спільний виклик падає з `Ошибка в параметрах командной строки` (§5.4).
- Вивід `ibcmd` має змішане кодування. Декодер розбирає **порядково**: строгий UTF-8, а на невалідних байтах — cp866 (§5.4).
- `.cfe` береться лише з `<воркспейс>/<workPath>/tools/YAxUnit-<версія>.cfe`, найвища версія. Kit нічого не завантажує (§5.4).
- `runner: va` приймається схемою, але драйвера немає: рядок «не перевіряється», на код виходу не впливає (§5.6).
- Жива база людини не чіпається: база лише з `Resolve-KitAgentBase` (§5.5). Платформа — лише через `Invoke-V8Designer` / `Invoke-V8Ibcmd`, обидва перевіряють ліцензію `Assert-NoLicenseProblem` (§5.5).
- `templates/settings.json` не змінюється (§6.2).
- Версія плагіна `1.2.0` → `1.3.0` з рядком в `upgrades.md`. План D1 уже підняв її до `1.2.0`; якщо D1 ще не виконано — спершу D1.
- Проєктні константи виконавця (коміт, мова, форми прогону тестів, контракт звіту) — `.claude/skills/kit-dev/references/subagent-brief.md`. Новий тест на фразу з виводу — лише після `grep` цієї фрази по `tools/commands/` і `tools/lib/`: вона мусить траплятись лише в перевірюваній гілці (kit-dev, case 22).
- `Integration`-тест (реальна платформа) — один прогін у фіналі блоку, з підтвердженням людини (kit-dev, case 8). Виконавець-субагент його **не запускає**.

## Review Focus

- **`minVersion: 25.10` без лапок.** YAML читає `Decimal`, і якщо код колись перейде з `[string]` на `[double]`, `25.10` мовчки стане `25.1`, тобто вимога знизиться. Очікування: `MinVersion` дорівнює рядку `'25.10'`. Тест — Task 1.
- **Змішане кодування в одному виводі** (рядок `[ERROR]` у UTF-8 і рядок платформи в cp866). Очікування: обидва рядки читабельні. Декодер «усе з cp866» чи «усе з UTF-8» зламав би один із них. Тест — Task 2.
- **Серверна база, розширення вже є.** Очікування: зупинка з інструкцією, а **не** «контур цілий». Вигідно було б прочитати «є» як «добре», але прапорців ніхто не бачив. Тест — Task 3.
- **`-Apply` на серверній базі без розширення.** Очікування: kit встановлює, перечитує й зупиняється з кодом `1` і інструкцією про прапорці. Не `0`. Тест послідовності рішень — Task 3.
- **Непередбачений вивід `ibcmd`** (код 2 на `--user` з кирилицею й дужками, код 127). Очікування: зупинка з сирим текстом платформи, без мовчазного «розширення немає». Тест — Task 4.

```powershell
function ConvertFrom-KitTestsBlock {
    <#
    .SYNOPSIS
        tests: воркспейсу (спека 2026-09-23 §5.1) — що цьому воркспейсу потрібно від бази агента
        для тестів. Стан бази тут не читається: це вимога, а перевіряє її kit tests.
    .DESCRIPTION
        minVersion приводиться [string], а не [double]: powershell-yaml читає 25.10 як Decimal
        (і в лапках, і без — перевірено 2026-09-23), [string] зберігає «25.10», а [double] дав би
        25.1 — вимога мовчки знизилась би.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)][AllowNull()]$Raw, [Parameter(Mandatory)][string]$Where)

    if ($Raw -isnot [System.Collections.IList] -or $Raw.Count -eq 0) {
        throw "$Where — tests: має бути непорожнім списком, наприклад: - runner: yaxunit"
    }
    $seen = @{}
    foreach ($t in $Raw) {
        Assert-KitMapKeys -Map $t -Allowed @('runner', 'extension', 'minVersion') -Required @('runner') -Where "$Where, елемент tests"
        $runner = [string]$t['runner']
        if ($script:TestRunners -notcontains $runner) {
            throw "$Where — runner: '$runner' невідомий. Відомі: $($script:TestRunners -join ', ')."
        }
        if ($seen.ContainsKey($runner)) { throw "$Where — runner: '$runner' оголошено двічі." }
        $seen[$runner] = $true

        $extension = $null
        if ($script:DefaultRunnerExtension.ContainsKey($runner)) {
            $extension = $script:DefaultRunnerExtension[$runner]
            if ($t.Contains('extension')) { $extension = [string]$t['extension'] }
            if ([string]::IsNullOrWhiteSpace($extension)) { throw "$Where — extension: порожній." }
        } elseif ($t.Contains('extension')) {
            throw "$Where — runner: $runner не є розширенням конфігурації, extension: тут не буває."
        }

        $minVersion = $null
        if ($t.Contains('minVersion')) {
            $minVersion = [string]$t['minVersion']
            if ($minVersion -notmatch '^\d+(\.\d+)*$') {
                throw "$Where — minVersion: '$minVersion' не схожий на версію (очікується 25.12 чи 24.09.1)."
            }
        }
        [pscustomobject]@{ Runner = $runner; Extension = $extension; MinVersion = $minVersion }
    }
}
```

У `Read-KitManifest`, у циклі `foreach ($ws in $wsRaw)`:
- `Assert-KitMapKeys -Map $ws -Allowed @('path', 'sources') …` → `-Allowed @('path', 'sources', 'tests')`;
- перед `$workspaces.Add(...)`:

```powershell

```

`ConvertFrom-KitTestsBlock` не експортувати: це внутрішній крок `Read-KitManifest`.

```powershell
    <#
    .SYNOPSIS
        ibcmd.exe тієї самої платформи, що й 1cv8.exe (тека bin). Окремого пошуку версії немає:
        розійтись версіями 1cv8 і ibcmd в одному процесі kit не має права.
    #>
    [CmdletBinding()]
    param([string]$V8Path)
    if (-not $V8Path) { $V8Path = Get-V8Path }
    $p = Join-Path (Split-Path -Parent $V8Path) 'ibcmd.exe'
    if (-not (Test-Path -LiteralPath $p -PathType Leaf)) {
        throw "ibcmd.exe не знайдено поруч із платформою: $p. Він ставиться разом із платформою 1С (компонент «Сервер 1С:Предприятия» чи «Администрирование»)."
    }
    $p
}

function ConvertFrom-V8ConsoleBytes {
    <#
    .SYNOPSIS
        Вивід ibcmd/платформи → текст. Кодування змішане (вимір 2026-09-23, спека §5.4): рядки
        [INFO]/[ERROR] ibcmd — UTF-8 без BOM, низькорівневі повідомлення платформи й помилки
        розбору параметрів — cp866, /Out-логи — UTF-8 з BOM. Тому декодується ПОРЯДКОВО:
        строгий UTF-8, а на невалідних байтах — cp866. Декодер «усе з cp866» зіпсував би UTF-8
        рядки, і навпаки.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)][AllowEmptyCollection()][byte[]]$Bytes)

    if ($Bytes.Length -eq 0) { return '' }
    $offset = 0
    if ($Bytes.Length -ge 3 -and $Bytes[0] -eq 0xEF -and $Bytes[1] -eq 0xBB -and $Bytes[2] -eq 0xBF) { $offset = 3 }
    $strict = [System.Text.UTF8Encoding]::new($false, $true)
    $cp866  = [System.Text.Encoding]::GetEncoding(866)
    $lines  = [System.Collections.Generic.List[string]]::new()
    $start  = $offset
    for ($i = $offset; $i -le $Bytes.Length; $i++) {
        if ($i -lt $Bytes.Length -and $Bytes[$i] -ne 0x0A) { continue }
        $len  = $i - $start
        $line = ''
        if ($len -gt 0) {
            try { $line = $strict.GetString($Bytes, $start, $len) }
            catch [System.Text.DecoderFallbackException] { $line = $cp866.GetString($Bytes, $start, $len) }
        }
        $lines.Add($line.TrimEnd("`r"))
        $start = $i + 1
    }
    ($lines -join "`n").TrimEnd()
}

function Invoke-V8Ibcmd {
    <#
    .SYNOPSIS
        Запуск ibcmd.exe: код виходу й декодований вивід (stdout, потім stderr). Ліцензія —
        той самий Assert-NoLicenseProblem, що й у Invoke-V8Designer.
    .DESCRIPTION
        Аргументи — готові фрагменти командного рядка (значення з пробілами викликач бере в
        лапки сам: --db-path="C:\…"). Вивід читається байтами з перенаправлених файлів, а не з
        конвеєра PowerShell: конвеєр декодував би все одним кодуванням консолі.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)][string[]]$Arguments, [string]$IbcmdPath)

    if (-not $IbcmdPath) { $IbcmdPath = Get-V8IbcmdPath }
    $id  = [guid]::NewGuid().ToString('N')
    $out = [System.IO.Path]::Combine([System.IO.Path]::GetTempPath(), "ibcmd-$id.out")
    $err = [System.IO.Path]::Combine([System.IO.Path]::GetTempPath(), "ibcmd-$id.err")
    $argLine = $Arguments -join ' '
    Write-Verbose "ibcmd $argLine"
    try {
        $proc = Start-Process -FilePath $IbcmdPath -ArgumentList $argLine -Wait -NoNewWindow -PassThru `
            -RedirectStandardOutput $out -RedirectStandardError $err
        $parts = foreach ($f in $out, $err) {
            if (Test-Path -LiteralPath $f) { ConvertFrom-V8ConsoleBytes -Bytes ([System.IO.File]::ReadAllBytes($f)) }
        }
        $text = (@($parts | Where-Object { $_ }) -join "`n")
    } finally {
        Remove-Item -LiteralPath $out, $err -Force -ErrorAction SilentlyContinue
    }
    Assert-NoLicenseProblem -Output $text
    [pscustomobject]@{ ExitCode = $proc.ExitCode; Output = $text }
}
```

```powershell
Set-StrictMode -Version Latest

# Тестовий контур бази агента (спека 2026-09-23 §5). Модуль нічого не імпортує сам: V8.psm1

function ConvertFrom-KitIbcmdExtensionInfo {
    <#
    .SYNOPSIS
        Вивід `ibcmd extension info` (рядки `key : value`, вимір 2026-09-23) → версія й прапорці.
        Нерозбірний текст — throw з самим текстом: «не розібрав» ніколи не читається як
        «прапорці зняті» чи «розширення немає».
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)][AllowEmptyString()][string]$Text)

    $map = @{}
    foreach ($line in ($Text -split "`r?`n")) {
        if ($line -match '^\s*(?<k>[a-z][a-z-]*)\s*:\s*(?<v>.*?)\s*$') { $map[$Matches['k']] = $Matches['v'].Trim('"') }
    }
    if (-not $map.ContainsKey('name')) { throw "Вивід ibcmd extension info не схожий на опис розширення (немає рядка name):`n$Text" }
    foreach ($k in 'safe-mode', 'unsafe-action-protection') {
        if ($map[$k] -notin @('yes', 'no')) { throw "Вивід ibcmd extension info: ${k}: '$($map[$k])' — очікувалось yes або no.`n$Text" }
    }
    [pscustomobject]@{
        Name = $map['name']; Version = $map['version']
        SafeMode = ($map['safe-mode'] -eq 'yes'); UnsafeActionProtection = ($map['unsafe-action-protection'] -eq 'yes')
    }
}

function Compare-KitVersion {
    <#
    .SYNOPSIS
        Порівняння версій покомпонентно як чисел: 24.9 < 24.10, 25.12 = 25.12.0.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)][string]$Left, [Parameter(Mandatory)][string]$Right)
    foreach ($v in $Left, $Right) { if ($v -notmatch '^\d+(\.\d+)*$') { throw "'$v' не схожий на версію." } }
    $l = @($Left.Split('.') | ForEach-Object { [int]$_ })
    $r = @($Right.Split('.') | ForEach-Object { [int]$_ })
    for ($i = 0; $i -lt [Math]::Max($l.Count, $r.Count); $i++) {
        $a = if ($i -lt $l.Count) { $l[$i] } else { 0 }
        $b = if ($i -lt $r.Count) { $r[$i] } else { 0 }
        if ($a -ne $b) { return [Math]::Sign($a - $b) }
    }
    0
}

function Find-KitRunnerPackage {
    <#
    .SYNOPSIS
        Пакет раннера, який поклала operation=tools-download Уніки: <воркспейс>/<workPath>/tools/,
        найвища версія. Kit нічого не завантажує й шлях у маніфест не пише (спека §5.4).
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)]$Workspace, [Parameter(Mandatory)][string]$Runner)

    $pattern = switch ($Runner) {
        'yaxunit' { '^YAxUnit-(?<v>\d+(\.\d+)*)\.cfe$' }
        default   { throw "Пакета для runner '$Runner' kit не шукає (спека §5.6)." }
    }
    $dir = Join-Path (Join-Path $Workspace.FullPath $Workspace.Project.WorkPath) 'tools'
    $best = $null
    foreach ($f in @(Get-ChildItem -LiteralPath $dir -File -ErrorAction SilentlyContinue)) {
        if ($f.Name -notmatch $pattern) { continue }
        $cand = [pscustomobject]@{ Path = $f.FullName; Version = $Matches['v'] }
        if ($null -eq $best -or (Compare-KitVersion -Left $cand.Version -Right $best.Version) -gt 0) { $best = $cand }
    }
    $best
}

function New-KitExtensionState {
    <#
    .SYNOPSIS
        Стан розширення в базі агента — одна форма для обох типів бази. Known = $false означає
        «версії й прапорців kit не бачить» (серверна база, спека §5.4), а не «їх немає».
    #>
    [CmdletBinding()]
    param([switch]$Present, [switch]$Known, [string]$Version, [switch]$SafeMode, [switch]$UnsafeActionProtection)
    [pscustomobject]@{
        Present = [bool]$Present; Known = [bool]$Known; Version = $(if ($Version) { $Version } else { $null })
        SafeMode = [bool]$SafeMode; UnsafeActionProtection = [bool]$UnsafeActionProtection
    }
}

function Get-KitTestContourDecision {
    <#
    .SYNOPSIS
        Рішення за станом (спека §5.3–§5.4, Р2): ok / deliver (дії, які -Apply виконає) / stop
        (причини з дією людини). Чиста функція — жодної платформи, тому вся логіка «що можна
        на якій базі» тестується тут, а команда лише виконує дії й перепитує.
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]$Spec,
        [Parameter(Mandatory)][ValidateSet('file', 'server')][string]$BaseKind,
        [Parameter(Mandatory)]$State,
        [AllowNull()]$Package
    )

    $ext = $Spec.Extension; $min = $Spec.MinVersion
    $actions = [System.Collections.Generic.List[object]]::new()
    $stops   = [System.Collections.Generic.List[string]]::new()
    $packageFits = $null -ne $Package -and (-not $min -or (Compare-KitVersion -Left $Package.Version -Right $min) -ge 0)
    $install = { $actions.Add([pscustomobject]@{ Kind = 'install'; Path = $Package.Path; Version = $Package.Version }) }
    $noPackage = {
        param([string]$Why)
        if ($null -eq $Package) { $stops.Add("$Why, а пакета в build/tools/ немає — $($script:DownloadHint).") }
        else { $stops.Add("$Why, а пакет у build/tools/ — версії $($Package.Version), нижчої за minVersion $min — $($script:DownloadHint).") }
    }

    if (-not $State.Present) {
        if ($packageFits) { & $install } else { & $noPackage "Розширення $ext у базі агента немає" }
    } elseif (-not $State.Known) {
        $need = if ($min) { ", версія не нижча за $min" } else { '' }
        $stops.Add("Розширення $ext у серверній базі агента є, але її версії й прапорців kit не читає (спека 2026-09-23 §5.4, спайк §8). " +
                   "Перевірте в Конфигураторі: Конфигурация → Расширения конфигурации → $ext — «Безопасный режим» і «Защита от опасных действий» зняті$need. " +
                   'Без цього YaXUnit падає на читанні свого конфігу, а Уніка каже лише timed out.')
    } else {
        if ($min -and $State.Version -and (Compare-KitVersion -Left $State.Version -Right $min) -lt 0) {
            if ($packageFits) { & $install } else { & $noPackage "Розширення $ext у базі — версії $($State.Version), нижчої за minVersion $min" }
        }
        if ($State.SafeMode -or $State.UnsafeActionProtection) {
            $actions.Add([pscustomobject]@{ Kind = 'unlock'; Path = $null; Version = $null })
        }
    }

    $status = if ($stops.Count) { 'stop' } elseif ($actions.Count) { 'deliver' } else { 'ok' }
    [pscustomobject]@{ Status = $status; Actions = $actions.ToArray(); Stops = $stops.ToArray() }
}
```

```powershell
function Get-KitIbcmdBaseArguments {
    # Спільні аргументи ibcmd для файлової бази агента. --user — лише коли в базі агента він є
    # (Resolve-KitAgentBase.User); пароля kit не зберігає (спека §2.5).
    param([Parameter(Mandatory)]$AgentBase)
    $a = @('--db-path="{0}"' -f $AgentBase.Path)
    if ($AgentBase.User) { $a += '--user="{0}"' -f $AgentBase.User }
    $a
}

function Get-KitExtensionState {
    <#
    .SYNOPSIS
        Стан розширення в базі агента (спека §5.4). Файлова — ibcmd extension info (Known).
        Серверна — лише імена з /DumpDBCfgList (не Known): ibcmd до неї через кластер не
        дістається (вимір 2026-09-23: код 127, іде до локальної бази автономного сервера).
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)]$AgentBase, [Parameter(Mandatory)][string]$Name)

    if ($AgentBase.Kind -eq 'file') {
        $r = Invoke-V8Ibcmd -Arguments (@('extension', 'info') + (Get-KitIbcmdBaseArguments -AgentBase $AgentBase) + @("--name=$Name"))
        if ($r.ExitCode -eq 0) {
            $i = ConvertFrom-KitIbcmdExtensionInfo -Text $r.Output
            return New-KitExtensionState -Present -Known -Version $i.Version -SafeMode:$i.SafeMode -UnsafeActionProtection:$i.UnsafeActionProtection
        }
        # Код 1 і «не найдено» — виміряна відповідь на відсутнє розширення. Будь-що інше (код 2 на
        # розборі --user, 127 — база не та) — не «розширення немає», а зупинка з текстом платформи.
        if ($r.ExitCode -eq 1 -and $r.Output -match 'не найдено|не знайдено|not found') { return New-KitExtensionState -Known }
        throw "ibcmd extension info для бази агента $($AgentBase.Path) завершився з кодом $($r.ExitCode):`n$($r.Output)"
    }

    $r = Invoke-V8Designer -IbSwitch $AgentBase.IbSwitch -User $AgentBase.User -Arguments @('/DumpDBCfgList -AllExtensions')
    Assert-V8InfobaseNotBusy -Output $r.Output -Infobase $AgentBase.Connection
    if ($r.ExitCode -ne 0) { throw "Перелік розширень бази агента ($($AgentBase.Connection)) не отримано, код $($r.ExitCode):`n$($r.Output)" }
    $names = @(($r.Output -split "`r?`n") | ForEach-Object { $_.Trim() } | Where-Object { $_ })
    New-KitExtensionState -Present:($names -contains $Name)
}

function Install-KitExtension {
    <#
    .SYNOPSIS
        Перше встановлення чи оновлення розширення з .cfe — ДВОМА викликами Конфігуратора:
        спільний /LoadCfg … /UpdateDBCfg дає «Ошибка в параметрах командной строки» (вимір
        2026-09-23). Успіх /UpdateDBCfg нічого не друкує — сигнал лише код 0.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)]$AgentBase, [Parameter(Mandatory)][string]$Name, [Parameter(Mandatory)][string]$CfePath)

    foreach ($step in @(
            @{ What = 'завантаження .cfe'; Args = @('/LoadCfg "{0}" -Extension {1}' -f $CfePath, $Name) },
            @{ What = 'оновлення конфігурації бази'; Args = @("/UpdateDBCfg -Extension $Name") })) {
        $r = Invoke-V8Designer -IbSwitch $AgentBase.IbSwitch -User $AgentBase.User -Arguments $step.Args
        Assert-V8InfobaseNotBusy -Output $r.Output -Infobase $AgentBase.Connection
        if ($r.ExitCode -ne 0) { throw "Встановлення розширення $Name ($($step.What)) завершилось з кодом $($r.ExitCode): $($r.Output)" }
    }
}

function Unlock-KitExtension {
    <#
    .SYNOPSIS
        Зняти безпечний режим і захист від небезпечних дій (ibcmd extension update). Лише
        файлова база: на серверній ibcmd не дістається до бази через кластер (спека §5.4);
        шлях через Підприємство — спайк §8.
    #>
    [CmdletBinding()]
    param([Parameter(Mandatory)]$AgentBase, [Parameter(Mandatory)][string]$Name)

    if ($AgentBase.Kind -ne 'file') {
        throw "Знімати прапорці розширення $Name на серверній базі kit не вміє (спека 2026-09-23 §5.4, спайк §8) — це робить людина в Конфигураторі."
    }
    $r = Invoke-V8Ibcmd -Arguments (@('extension', 'update') + (Get-KitIbcmdBaseArguments -AgentBase $AgentBase) + @("--name=$Name", '--safe-mode=no', '--unsafe-action-protection=no'))
    if ($r.ExitCode -ne 0) { throw "ibcmd extension update для $Name завершився з кодом $($r.ExitCode):`n$($r.Output)" }
}
```

```powershell
function Invoke-KitTests {
    <#
    .SYNOPSIS
        Тестовий контур бази агента (спека 2026-09-23 §5): чи готова база до operation=test.
        Без -Apply лише читає; з -Apply доставляє відсутнє й ПЕРЕПИТУЄ — код визначає повторна
        перевірка, тож ідемпотентність доводиться щоразу, а не декларується.
    .DESCRIPTION
        Коди: 0 — контур цілий; 3 — є що доставити, і -Apply це вміє; 1 — зупинка, потрібна людина.
    #>
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]$Context,
        [string]$Workspace,
        [string]$Source,
        [bool]$Apply,
        [switch]$AsJson
    )

    $workspaces = @($Context.Workspaces)
    if ($Workspace -or $Source) {
        # Звуження — наявною Select-KitSources (правильні зупинки на невідомому ключі й на ключі
        # у кількох воркспейсах), як у provision: база агента належить воркспейсу, не джерелу.
        $wsPaths = @(@(Select-KitSources -Context $Context -Workspace $Workspace -Source $Source).Workspace | Sort-Object -Unique)
        if ($Workspace -and -not $Source) { $wsPaths = @($Workspace) }
        $workspaces = @($workspaces | Where-Object { $wsPaths -contains $_.Path })
    }

    $signals = [System.Collections.Generic.List[object]]::new()
    $lines   = [System.Collections.Generic.List[string]]::new()

    foreach ($ws in $workspaces) {
        $specs = @($ws.Tests)
        if ($specs.Count -eq 0) { $lines.Add("- $($ws.Path): tests: у маніфесті не оголошено — пропущено."); continue }
        $testSources = @($ws.Sources | Where-Object { $_.Truth -eq 'git' -and $_.Type -eq 'EXTENSION' })

        foreach ($spec in $specs) {
            $sig = [pscustomobject]@{
                Workspace = $ws.Path; Runner = $spec.Runner; Extension = $spec.Extension; BaseKind = $null; Status = $null
                Present = $null; Version = $null; SafeMode = $null; UnsafeActionProtection = $null
                Actions = @(); Done = @(); Stops = @(); TestExtensions = @(); Text = $null
            }
            $label = "$($ws.Path) / $($spec.Runner)"
            try {
                if ($spec.Runner -eq 'va') {
                    $sig.Status = 'skipped'
                    $sig.Text = "- ${label}: va: драйвер ще не реалізовано (спека 2026-09-23 §5.6) — стан не перевіряється."
                } elseif ($testSources.Count -eq 0) {
                    $sig.Status = 'stop'
                    $sig.Stops = @("у воркспейсі немає джерела truth: git типу EXTENSION — тестам нема звідки взятись. Оголосіть тестовий source-set: скіл v8storagekit:onboarding, «тестовий source-set».")
                } else {
                    $ab = Resolve-KitAgentBase -Context $Context -Workspace $ws
                    if ($null -eq $ab) {
                        $sig.Status = 'stop'
                        $sig.Stops = @("у $($ws.Path)/v8project.yaml немає infobase: — бази агента немає, тестам нема де виконуватись.")
                    } elseif (-not $ab.Exists) {
                        $sig.Status = 'stop'
                        $sig.Stops = @("бази агента ще немає ($($ab.Path)) — kit provision -Workspace $($ws.Path) -Apply, далі operation=build Уніки.")
                    } else {
                        $sig.BaseKind = $ab.Kind
                        $package = Find-KitRunnerPackage -Workspace $ws -Runner $spec.Runner
                        $state = Get-KitExtensionState -AgentBase $ab -Name $spec.Extension
                        $decision = Get-KitTestContourDecision -Spec $spec -BaseKind $ab.Kind -State $state -Package $package
                        $done = [System.Collections.Generic.List[string]]::new()
                        # Два раунди досить: install (розширення з'явилось, прапорці yes) → unlock.
                        for ($round = 1; $Apply -and $decision.Status -eq 'deliver' -and $round -le 2; $round++) {
                            foreach ($a in $decision.Actions) {
                                switch ($a.Kind) {
                                    'install' { Install-KitExtension -AgentBase $ab -Name $spec.Extension -CfePath $a.Path; $done.Add("встановлено $($spec.Extension) $($a.Version) з $($a.Path)") }
                                    'unlock'  { Unlock-KitExtension -AgentBase $ab -Name $spec.Extension; $done.Add('знято безпечний режим і захист від небезпечних дій') }
                                }
                            }
                            $state = Get-KitExtensionState -AgentBase $ab -Name $spec.Extension
                            $decision = Get-KitTestContourDecision -Spec $spec -BaseKind $ab.Kind -State $state -Package $package
                        }
                        $sig.Status = $decision.Status; $sig.Stops = @($decision.Stops); $sig.Done = $done.ToArray()
                        $sig.Actions = @($decision.Actions | ForEach-Object { if ($_.Kind -eq 'install') { "встановити $($spec.Extension) $($_.Version)" } else { 'зняти безпечний режим і захист від небезпечних дій' } })
                        $sig.Present = $state.Present; $sig.Version = $state.Version
                        if ($state.Known) { $sig.SafeMode = $state.SafeMode; $sig.UnsafeActionProtection = $state.UnsafeActionProtection }

                        # Прапорці тестового розширення — лише доповідь (спека §5.3 п. 4, до спайку).
                        if ($ab.Kind -eq 'file') {
                            $sig.TestExtensions = @(foreach ($ts in $testSources) {
                                $t = Get-KitExtensionState -AgentBase $ab -Name $ts.Key
                                [pscustomobject]@{ Name = $ts.Key; Present = $t.Present; SafeMode = $t.SafeMode; UnsafeActionProtection = $t.UnsafeActionProtection }
                            })
                        }
                    }
                }
            } catch {
                # Непередбачений вивід платформи — зупинка з її текстом для ЦЬОГО раннера; решта
                # воркспейсів усе одно доповідається (спека §5.4, «Файлова база з користувачами»).
                $sig.Status = 'stop'; $sig.Stops = @($_.Exception.Message)
            }

            if (-not $sig.Text) {
                $head = "- ${label} ($($spec.Extension)" + $(if ($sig.BaseKind) { ", база $($sig.BaseKind)" } else { '' }) + '): '
                $parts = [System.Collections.Generic.List[string]]::new()
                if ($sig.Done.Count) { $parts.Add('зроблено: ' + ($sig.Done -join '; ')) }
                switch ($sig.Status) {
                    'ok'      { $parts.Add("контур цілий: $($spec.Extension) $($sig.Version), безпечний режим і захист зняті") }
                    'deliver' { $parts.Add('є що доставити: ' + ($sig.Actions -join '; ') + ' — kit tests -Apply') }
                    'stop'    { $parts.Add('ЗУПИНКА: ' + ($sig.Stops -join ' ')) }
                }
                foreach ($te in $sig.TestExtensions) {
                    $parts.Add("тестове розширення $($te.Name): " + $(if (-not $te.Present) { 'у базі немає — operation=build Уніки' } elseif ($te.SafeMode -or $te.UnsafeActionProtection) { 'у безпечному режимі (лише доповідь, спека §5.3)' } else { 'прапорці зняті' }))
                }
                $sig.Text = $head + ($parts -join '; ') + '.'
            }
            $lines.Add($sig.Text)
            $signals.Add($sig)
        }
    }

    if ($AsJson) {
        Write-Host (ConvertTo-Json -InputObject $signals.ToArray() -Depth 5)
    } else {
        Write-Host "kit tests — $($Context.Kind) $($Context.Label)"
        foreach ($l in $lines) {
            $color = if ($l -match 'ЗУПИНКА') { 'Red' } elseif ($l -match 'є що доставити') { 'Yellow' } else { 'Gray' }
            Write-Host $l -ForegroundColor $color
        }
    }

    $exit = if (@($signals | Where-Object Status -eq 'stop').Count) { 1 }
            elseif (@($signals | Where-Object Status -eq 'deliver').Count) { 3 }
            else { 0 }
    [pscustomobject]@{ ExitCode = $exit; Signals = $signals.ToArray() }
}

Export-ModuleMember -Function Invoke-KitTests
```

Про звуження: коли передано лише `-Workspace`, `Select-KitSources` перевіряє, що такий воркспейс є (зупинка з переліком), а далі береться саме він, навіть якщо джерел у ньому з потрібним `truth` немає. `-Source` звужує до воркспейсу цього джерела, як у `provision`.
